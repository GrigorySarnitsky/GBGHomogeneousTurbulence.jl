Propagator

GBGIsotropicTurbulence.Propagator — Module
Propagator

The interchangeable time-marching schemes, concrete AbstractIntegrator subtypes; a run chooses one as the integrator of its Simulation. All are of the integrating-factor family: the stiff diffusive part is advanced exactly and the nonlinear term explicitly by a Runge–Kutta stage combination.

  • IFLowStorageRK3 (the default), IFRK2 — the schemes (RK3 low-storage; IFRK2/Heun a cheaper two-stage alternative, imaginary-axis unstable).
  • IntegratorBuffers, allocate_buffers — the preallocated per-step scratch.
  • step! — advance the coupled velocity and passive scalar one timestep.
  • recommended_cfl — a scheme's advective-CFL ceiling.

Integrator schemes

The integrating-factor scheme supertype and its concretes — the default third-order low-storage RK3, then the cheaper, imaginary-axis-unstable second-order Heun.

GBGIsotropicTurbulence.Propagator.AbstractIntegrator — Type
AbstractIntegrator

Supertype of the time-marching schemes. A scheme implements step!(integrator, state, domain, buffers, conditions, dt), advancing the state's velocity $\hat{\boldsymbol u}$ and scalar $\hat\varphi$ (both in spectral representation) by one timestep in place, and may specialize recommended_cfl.

GBGIsotropicTurbulence.Propagator.IFLowStorageRK3 — Type
IFLowStorageRK3()

Integrating-factor third-order low-storage Runge–Kutta (Williamson 1980, 2N-storage). With the diffusive integrating factor $\mathcal{E}_D(\tau)$ built by integrating_factor! over a substep interval $\tau$ ($D = \nu$ for the velocity, $\varkappa = \nu/\mathrm{Sc}$ for the scalar) and $\widehat{\boldsymbol{N}}$ the dealiased nonlinearity of each field, the step carries a state $\hat q$ and a single accumulator $\boldsymbol{h}$ through three stages $i = 1,2,3$,

\[\begin{aligned} \boldsymbol{h} &\leftarrow A_i\,\boldsymbol{h} + \Delta t\,\widehat{\boldsymbol{N}}(\hat q), \\ \hat q &\leftarrow \hat q + B_i\,\boldsymbol{h}, \\ \hat q &\leftarrow \mathcal{E}_D(d_i\Delta t)\,\hat q, \\ \boldsymbol{h} &\leftarrow \mathcal{E}_D(d_i\Delta t)\,\boldsymbol{h}, \end{aligned}\]

with $A = (0, -5/9, -153/128)$, $B = (1/3, 15/16, 8/15)$, and node increments $d = (1/3, 5/12, 1/4)$ (abscissae $c = (0, 1/3, 3/4)$). The velocity and scalar are advanced in lockstep (the same $A,B,d$), each with its own diffusivity. Three nonlinear evaluations per step, two field registers per field — the default workhorse: third-order and stable on the imaginary axis (limit $\sqrt{3}$), unlike IFRK2.

source
GBGIsotropicTurbulence.Propagator.IFRK2 — Type
IFRK2()

Integrating-factor second-order Runge–Kutta (Heun). With the velocity and scalar integrating factors $\mathcal{E}_\nu$ and $\mathcal{E}_\varkappa$ (the diffusive kernel of integrating_factor! at $D = \nu$ and $D = \varkappa = \nu/\mathrm{Sc}$ over the step $\Delta t$) and $\widehat{\boldsymbol{N}}$ each field's dealiased nonlinearity, one step of a field $\hat q$ with integrating factor $\mathcal{E}$ is

\[\begin{aligned} \hat q^{*} &= \mathcal{E}\,(\hat q_n + \Delta t\,\widehat{\boldsymbol{N}}_1), \\ \hat q_{n+1} &= \mathcal{E}\,\hat q_n + \tfrac{\Delta t}{2}\big(\mathcal{E}\,\widehat{\boldsymbol{N}}_1 + \widehat{\boldsymbol{N}}_2\big), \end{aligned}\]

with $\widehat{\boldsymbol{N}}_1$ at $\hat q_n$ and $\widehat{\boldsymbol{N}}_2$ at the predictor $\hat q^{*}$; velocity and scalar use $\mathcal{E}_\nu$ and $\mathcal{E}_\varkappa$ respectively, then the forcings are applied. Two nonlinear evaluations per step.

Note

Every second-order two-stage explicit Runge–Kutta has stability function $R(z) = 1 + z + z^{2}/2$, for which $\lvert R(\mathrm{i}y)\rvert^{2} = 1 + y^{4}/4 > 1$: the scheme is unstable on the imaginary axis, so it is stable only where the viscous damping of the integrating factor dominates. It is adequate for well-resolved, modest-Reynolds-number runs but is not the default — prefer IFLowStorageRK3 for high Reynolds number or marginal resolution.

Step scratch

The preallocated per-step working set the integrator writes into — built per concrete scheme, sized so a step allocates no field-sized memory.

GBGIsotropicTurbulence.Propagator.IntegratorBuffers — Type
IntegratorBuffers

The preallocated per-step scratch the integrator writes into, sized so a step allocates no field-sized memory. Built per scheme by allocate_buffers(integrator, domain; scalar), which allocates exactly that scheme's working set: a register another scheme would use is left nothing, never allocated.

Fields

Shared — every scheme allocates these:

  • velocity_copy, vorticity_spectral — working space in spectral representation that the velocity/vorticity recovery consumes.
  • product_physical, product_spectral — the quadratic products in physical and spectral representation (the Lamb vector $\boldsymbol{u}\times\boldsymbol{\omega}$, and the scalar flux $\boldsymbol{u}\varphi$).
  • velocity_physical, vorticity_start, vorticity_physical, velocity_star — the start-of-step and substage velocity/vorticity registers in physical representation.
  • stage1 — the first Runge–Kutta stage register (the accumulator for IFLowStorageRK3, the first stage for IFRK2).
  • integrating_factor, velocity_rate — the shared viscous integrating factor and the velocity's per-mode linear-forcing-rate array $A(\boldsymbol{\kappa})$.

Scheme-specific — allocated only for the scheme that uses it, else nothing:

  • nonlinear — the assembled nonlinear term (IFLowStorageRK3 only).
  • stage2, velocity_star_spectral — the second stage register and the substage velocity predictor $\hat{\boldsymbol{u}}^{*}$ in spectral representation (IFRK2 only).

Nested:

  • scalar — a ScalarBuffers for the passive scalar $\varphi$ when scalar = true, else nothing; when nothing, the run evolves no scalar and none of its field-sized buffers are allocated.
  • phase_shift — a PhaseShiftBuffers (the two translation kernels and the displaced-evaluation scratch) when the domain's dealiasing is PhaseShift, else nothing.

GBGIsotropicTurbulence.Propagator.allocate_buffers — Function
allocate_buffers(integrator, domain; scalar = false) -> IntegratorBuffers

Allocate the IntegratorBuffers integrator needs, dispatching on the concrete scheme so it allocates exactly its working set — never a register another scheme would use. IFLowStorageRK3 allocates stage1 + nonlinear; IFRK2 allocates stage1 + stage2

  • velocity_star_spectral. scalar = true adds the nested ScalarBuffers, likewise sized to the scheme.

A scheme with no method here is a hard error — there is no over-allocating fallback. The run layer calls this when assembling a Simulation.

Time stepping

One in-place step of the coupled velocity and passive scalar together through the shared RK stages.

GBGIsotropicTurbulence.Propagator.step! — Function
step!(integrator, state, domain, buffers, conditions, dt)

Advance the state (a ResolvedFields holding the velocity $\hat{\boldsymbol u}$ and passive scalar $\hat\varphi$ in spectral representation) by one timestep dt in place, using the integrator, domain, buffers, and the problem conditions (a FlowConditions). Dispatches on the concrete integrator type (see IFRK2, IFLowStorageRK3). The caller must have filled buffers.velocity_physical and buffers.vorticity_start with the start-of-step velocity and vorticity in physical representation (via velocity_to_physical! and vorticity_to_physical!).

Timestep ceiling

A scheme's advective-CFL ceiling.

GBGIsotropicTurbulence.Propagator.recommended_cfl — Function
recommended_cfl(integrator, domain)

A conservative advective-CFL ceiling $C$ for the scheme, for a timestep $\Delta t = C\,\Delta x / \max_i\lvert u_i\rvert$.

The advective eigenvalues of the dealiased system are imaginary, of magnitude up to $\kappa_{\max}\max\lvert\boldsymbol{u}\rvert$; stability needs this times $C$ to stay within the scheme's imaginary-axis stability limit $y_{\mathrm{s}}$. The base ceiling is calibrated for the $2/3$ rule ($\kappa_{\max}\Delta x = 2\pi/3 \approx 2.09$): for IFLowStorageRK3 $y_{\mathrm{s}} = \sqrt{3}$ gives $C \lesssim 0.83$, taken conservatively as $0.5$; IFRK2 is imaginary-axis unstable ($y_{\mathrm{s}} = 0$, relying on viscous damping), so a small $0.25$.

It scales that base by the domain's dealiasing: a strategy that keeps modes to a higher $\kappa_{\max}$ (e.g. HouLi, out to the Nyquist wavenumber) takes a proportionally smaller step, $C \propto 1/\kappa_{\max}$. This is the value Simulation uses; override cfl for a specific run.
