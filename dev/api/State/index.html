State

GBGIsotropicTurbulence.State — Module
State

The evolving state a run advances, and how it is recovered and seeded:

  • ResolvedFields — the inert record of the evolving velocity and scalar in spectral representation (the single source of truth; the physical fields are recovered from it, never held here).
  • velocity_to_physical!, vorticity_to_physical!, scalar_to_physical! — recover the velocity, vorticity, and scalar in physical representation from the spectral state.
  • random_solenoidal_velocity! and random_scalar! — the random initial conditions (a divergence-free velocity, a mean-zero scalar) that seed it.

All sized to a FixedDomain. The boundary storage the recoveries fill is the ObservablesCache.

The state

The evolving fields a run advances, in spectral representation — the single source of truth.

GBGIsotropicTurbulence.State.ResolvedFields — Type
ResolvedFields(domain; scalar = false)

The inert record of the evolving fields a run advances, in spectral representation — the single source of truth. The velocity, vorticity, and scalar in physical representation are recoveries of it, not part of it: the iteration recovers them into the stamped slots of the ObservablesCache at its tail (never on a read — a cached read serves the deposited value or throws), so the state itself cannot go stale. Build it on a FixedDomain; pass scalar = true to carry a passive scalar.

Fields

  • velocity — the velocity in spectral representation, $\hat{\boldsymbol{u}}$.
  • scalar — the scalar in spectral representation, $\hat\varphi$, or nothing when the run carries no passive scalar.

Physical-field recovery

Recover the velocity, vorticity, and scalar in physical representation from the state in spectral representation (the sources are preserved) — the recoveries the iteration's tail deposits and the nonlinear assemblies consume.

GBGIsotropicTurbulence.State.velocity_to_physical! — Function
velocity_to_physical!(u, û, domain, spectral_scratch)

Recover the velocity in physical representation into u, from the spectral û (left unchanged), on the FixedDomain domain whose transform plans carry it. The scratch spectral_scratch (a vector field in spectral representation) is the working space.

GBGIsotropicTurbulence.State.vorticity_to_physical! — Function
vorticity_to_physical!(ω, û, domain, spectral_scratch)

Compute the vorticity $\boldsymbol{\omega} = \nabla\times\boldsymbol{u}$ in physical representation into ω, from the velocity û in spectral representation, leaving û untouched. The spectral vorticity $\mathrm{i}\boldsymbol{\kappa}\times\hat{\boldsymbol{u}}$ is formed in the scratch spectral_scratch (a vector field in spectral representation) and transformed to physical representation by the FixedDomain domain's plans.

Random initial conditions

Seed a large-scale-peaked, dealiased, rescaled random solenoidal velocity, or a mean-zero scalar.

GBGIsotropicTurbulence.State.random_solenoidal_velocity! — Function
random_solenoidal_velocity!(û, domain; kinetic_energy, peak_wavenumber,
                            spectrum = nothing, rng = default_rng())

Fill û (a velocity field in spectral representation) with a random, divergence-free velocity $\boldsymbol{u}$ of a chosen energy spectrum, dealiased and rescaled so the kinetic energy $\tfrac{1}{2}\langle\lvert\boldsymbol{u}\rvert^{2}\rangle$ equals kinetic_energy. The Leray–Helmholtz projection $\mathbb{P}$ enforces $\nabla\cdot\boldsymbol{u} = 0$.

By default (spectrum = nothing) the velocity is concentrated at large scales by a Gaussian envelope $\exp\!\big(-\lvert\boldsymbol{\kappa}\rvert^{2}/\kappa_p^{2}\big)$ on the mode amplitudes (zeroed at $\boldsymbol{\kappa} = \boldsymbol{0}$, so the mean mode stays empty), whose characteristic wavenumber is $\kappa_p$ (peak_wavenumber). Because the envelope multiplies the amplitudes, the shell-summed energy spectrum $\propto \kappa^{2}\exp\!\big(-2\kappa^{2}/\kappa_p^{2}\big)$ peaks at $\kappa_p/\sqrt{2}$, not at $\kappa_p$ itself (the $\kappa^{2}$ is the shell's mode count). Pass spectrum, a function $\kappa \mapsto E(\kappa)$ giving a target radial energy spectrum, to seed that shape instead: each mode is scaled by $\sqrt{E(\kappa)}/\kappa$, so the shell-summed spectrum is $\propto \kappa^{2}(\sqrt{E}/\kappa)^{2} = E(\kappa)$ (the $\kappa^{2}$ is the shell's mode count) and the overall amplitude is fixed by the kinetic_energy rescaling — e.g. a von Kármán or Pope form from the Phenomenology submodule's model spectra, which the run layer can wire in for you.

The domain (a FixedDomain) is what the field is generated on; the rng is the random stream (defaults to Random.default_rng()).

Note

Seeding into a running case mutates the resolved fields out of band — announce it with resolved_fields_modified!, and re-deposit with deposit! before advancing (cached reads throw in between; nothing is recomputed on a read).

GBGIsotropicTurbulence.State.random_scalar! — Function
random_scalar!(φ̂, domain; scalar_variance, peak_wavenumber,
               spectrum = nothing, rng = default_rng())

Fill φ̂ (the scalar $\varphi$ in spectral representation) with a random, mean-zero scalar of a chosen spectrum, dealiased and rescaled so the variance $\langle\varphi^{2}\rangle$ equals scalar_variance. The mean vanishes by construction: the envelope is zeroed at $\boldsymbol{\kappa}=\boldsymbol{0}$, and that mode's coefficient is the spatial mean $\langle\varphi\rangle$.

By default (spectrum = nothing) the scalar is concentrated at large scales by a Gaussian envelope $\exp\!\big(-\lvert\boldsymbol{\kappa}\rvert^{2}/\kappa_p^{2}\big)$ on the mode amplitudes — zeroed, as above, at the origin — whose characteristic wavenumber is $\kappa_p$ (peak_wavenumber). Because the envelope multiplies the amplitudes, the shell-summed scalar-variance spectrum $\propto \kappa^{2}\exp\!\big(-2\kappa^{2}/\kappa_p^{2}\big)$ peaks at $\kappa_p/\sqrt{2}$, not at $\kappa_p$ itself (the $\kappa^{2}$ is the shell's mode count). Pass spectrum, a function $\kappa \mapsto E_\varphi(\kappa)$ giving a target radial scalar-variance spectrum, to seed that shape instead: each mode is scaled by $\sqrt{E_\varphi(\kappa)}/\kappa$ (the same construction the velocity uses), so the shell-summed spectrum is $\propto E_\varphi(\kappa)$ and the amplitude is fixed by the scalar_variance rescaling — e.g. an Obukhov–Corrsin form from Phenomenology.

The domain (a FixedDomain) is what the field is generated on; the rng is the random stream (defaults to Random.default_rng()).

Note

Seeding into a running case mutates the resolved fields out of band — announce it with resolved_fields_modified!, and re-deposit with deposit! before advancing (cached reads throw in between; nothing is recomputed on a read).
