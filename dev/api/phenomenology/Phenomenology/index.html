Reference laws — the interface

GBGIsotropicTurbulence.Phenomenology — Module
Phenomenology

Reference turbulence phenomenology — the fitted scalings, model spectra, and structure-function laws that theory and experiment have established, each an author-year parametrization of an abstract law family. This is the predicted counterpart to the measured Observables: a provider the validation layer reads to compare a run against, never a comparer itself and never assumed by the dynamics.

A law family is an abstract subtype of TurbulenceLaw (the root of every reference law here); each parametrization is a named preset — usually a concrete subtype carrying its fitted coefficients and its provenance, or (for the composed velocity spectra like Spectra.Pope2000) a factory function that assembles one. Choosing a law is choosing the preset (the published fit is the default); a name is disambiguated by its submodule (the quantity), its author-year (the paper), and a trailing letter (a same-year collision).

The flow state a law reads:

  • FlowParameters — the flow-state bundle a law evaluates against, with the derived scales kolmogorov_length, kolmogorov_time, taylor_microscale, taylor_reynolds, and scalar_diffusivity as helpers.
  • provenance — a law's citation and validity range (a Reference); fit is the (future) seam for fitting a parametrization to measured data.

The law families, one submodule per representation:

  • Spectra — model velocity and scalar spectra, functions of wavenumber, evaluated by spectrum.
  • StructureFunctions — the inertial-range laws and their intermittency exponents, evaluated by structure_function and scaling_exponent.
  • Scalings — the dimensionless constants and their Reynolds-number trends, evaluated by scaling.
Extraction-bound

Built inside GBGIsotropicTurbulence but designed to be cut into a standalone GBGTurbulencePhenomenology with no rewrite: it takes no field/statistics/dynamics dependency, and the umbrella does not re-export it — reach the laws opt-in through Phenomenology (using GBGIsotropicTurbulence.Phenomenology.Spectra).

The flow-state bundle

The flow state a law is evaluated against — the dimensional quantities from which each law forms its dimensionless groups.

GBGIsotropicTurbulence.Phenomenology.FlowParameters — Type
FlowParameters(; viscosity, dissipation, rms_velocity, integral_scale,
                 schmidt = 1.0, scalar_dissipation = NaN)

The flow-state bundle a law is evaluated against — the analogue of FlowConditions and FixedDomain on the phenomenology side. It carries the independent dimensional quantities of a homogeneous isotropic state ($\nu$, $\varepsilon$, $u'$, $L_{11}$); the small scales and the dimensionless Taylor-scale Reynolds number are derived from them, not stored.

Fields (all keyword; a homogeneous-isotropic state fixes the rest):

  • viscosity — the kinematic viscosity $\nu$.
  • dissipation — the mean dissipation rate $\varepsilon = \nu\langle\lvert\boldsymbol{\omega}\rvert^2\rangle$.
  • rms_velocity — the single-component r.m.s. velocity $u'$ (so the turbulent kinetic energy is $k = \tfrac{3}{2} u'^2$).
  • integral_scale — the longitudinal integral length $L_{11}$ (a large-scale quantity, independent of $\nu$ and $\varepsilon$; it fixes the energy-containing range).
  • schmidt — the Schmidt number $\mathrm{Sc}$ (the scalar diffusivity is $\varkappa = \nu/\mathrm{Sc}$); default 1.0.
  • scalar_dissipation — the scalar dissipation rate $\varepsilon_\varphi$ (only scalar laws read it); default NaN (unset).

The derived scales, computed from the bundle.

GBGIsotropicTurbulence.Phenomenology.kolmogorov_length — Function
kolmogorov_length(fp) -> Float64

The Kolmogorov (dissipation) length $\eta = (\nu^3/\varepsilon)^{1/4}$ of the state fp (a FlowParameters) — the scale at which viscosity terminates the cascade.

source
GBGIsotropicTurbulence.Phenomenology.kolmogorov_time — Function
kolmogorov_time(fp) -> Float64

The Kolmogorov time $\tau_\eta = (\nu/\varepsilon)^{1/2}$ of the state fp (a FlowParameters) — the turnover time of the smallest eddies.

source
GBGIsotropicTurbulence.Phenomenology.taylor_microscale — Function
taylor_microscale(fp) -> Float64

The Taylor microscale $\lambda = \sqrt{15 \nu u'^2/\varepsilon}$ of the state fp (a FlowParameters) — the intermediate scale set by the isotropic relation $\varepsilon = 15 \nu u'^2/\lambda^2$.

source
GBGIsotropicTurbulence.Phenomenology.taylor_reynolds — Function
taylor_reynolds(fp) -> Float64

The Taylor-scale Reynolds number $\mathrm{Re}_\lambda = u'\lambda/\nu$ of the state fp (a FlowParameters) — the standard measure of how developed the turbulence is, and the argument of every Scalings trend. Equivalently $\mathrm{Re}_\lambda = u'^2\sqrt{15/(\nu\varepsilon)}$.

source
GBGIsotropicTurbulence.Phenomenology.scalar_diffusivity — Function
scalar_diffusivity(fp) -> Float64

The scalar diffusivity $\varkappa = \nu/\mathrm{Sc}$ of the state fp (a FlowParameters) — the diffusivity of the passive scalar $\varphi$, set by the Schmidt number.

The law interface

The law supertype and its provenance.

GBGIsotropicTurbulence.Phenomenology.TurbulenceLaw — Type
TurbulenceLaw

Supertype of every reference law — a model spectrum, a structure-function law, or a scaling constant. A concrete law is a parametrization: it holds its fitted coefficients, reports its provenance, and implements the evaluator for its family (spectrum, structure_function, or scaling), all against a FlowParameters bundle.

source
GBGIsotropicTurbulence.Phenomenology.Reference — Type
Reference(citation; valid_Reλ = (0.0, Inf))

The provenance of a law: a citation string (a full author–year reference) and the Taylor-scale-Reynolds-number range valid_Reλ = (lo, hi) over which the fit is meant to hold. A comparison reads valid_Reλ so a law is not judged outside its stated domain.

source

The per-family evaluators — spectrum, structure_function / scaling_exponent, and scaling — a law's provenance, and the fit seam.

GBGIsotropicTurbulence.Phenomenology.provenance — Function
provenance(law) -> Reference

The Reference of a law (a TurbulenceLaw) — its citation and stated Reynolds-number validity range. Every parametrization implements it; it is the single source of the law's attribution.

source
GBGIsotropicTurbulence.Phenomenology.spectrum — Function
spectrum(law, κ, fp) -> Float64

The reference spectrum predicted by a model law at wavenumber κ for the state fp (a FlowParameters) — the velocity energy spectrum $E(\kappa)$ for an EnergySpectrum (the density in wavenumber of the kinetic energy, $k = \int_0^\infty E(\kappa)\,\mathrm d\kappa$), or the scalar spectrum $E_\varphi(\kappa)$ for a ScalarSpectrum. Its home and the composed form are in Spectra.

source
GBGIsotropicTurbulence.Phenomenology.structure_function — Function
structure_function(law, r, fp; order) -> Float64

The reference structure function of the given order predicted by a law (a StructureFunction) at separation r for the state fp (a FlowParameters). Most laws give the longitudinal velocity moment $D_{L\dots}(r) = \langle(\delta u_L)^p\rangle$ (the order-th moment $p$) of the velocity increment $\delta u_L$ across a distance r; a mixed velocity–scalar law (Yaglom1949) instead gives $\langle\delta u_L (\delta\varphi)^{2}\rangle$, the transport of scalar variance. Its home is StructureFunctions.

source
GBGIsotropicTurbulence.Phenomenology.scaling_exponent — Function
scaling_exponent(law; order) -> Float64

The inertial-range scaling exponent $\zeta_p$ of the order-$p$ longitudinal velocity structure function, $D_{L\dots}(r) \sim r^{\zeta_p}$, of the order $p$ requested, predicted by a law (a StructureFunction) — the self-similar $\zeta_p = p/3$ of K41, or the anomalous exponent of an intermittency model. Its home is StructureFunctions.

source
GBGIsotropicTurbulence.Phenomenology.scaling — Function
scaling(law, fp) -> Float64

The reference dimensionless constant predicted by a scaling law (a ScalingLaw) for the state fp (a FlowParameters) — a single number or its Reynolds-number trend (e.g. the normalized dissipation $C_\varepsilon$ or the Kolmogorov constant $C_K$). Its home is Scalings.

source
GBGIsotropicTurbulence.Phenomenology.fit — Function
fit(::Type{L}, ...) -> L

Fit a parametrization of law family L to measured data — the seam by which a run's own measurements become a parametrization sitting beside the literature. No methods are defined yet; it is the recorded extension point for fitting a run's own measurements to a parametrization.
