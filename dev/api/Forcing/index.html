Forcing

GBGIsotropicTurbulence.Forcing — Module
Forcing

The pluggable energy-injection strategies, concrete AbstractForcing subtypes. A strategy hooks into the step through up to four methods — forcing_rate! (a linear rate folded into the integrating factor), apply_forcing! (a post-step projection), prepare_forcing! (a per-step state advance), and forcing_source! (an additive per-stage source). NoForcing, BandRescaling, Linear, ConstantPower, and the stochastic StochasticOU are provided; one implementation serves both the velocity and the scalar $\varphi$.

Public API

GBGIsotropicTurbulence.Forcing.AbstractForcing — Type
AbstractForcing

Supertype of the energy-injection strategies. A strategy may implement any of forcing_rate! (a linear forcing rate folded into the integrating factor), apply_forcing! (a post-step projection), prepare_forcing! (a per-step state advance), and forcing_source! (an additive per-stage source); all default to doing nothing.

GBGIsotropicTurbulence.Forcing.BandRescaling — Type
BandRescaling(ops; energy, target = :band, lowest_shell = 1, highest_shell = 2)

Deterministic constant-energy forcing (post-step). Each step the in-band Fourier modes (integer shells $\texttt{lowest\_shell} \le \kappa \le \texttt{highest\_shell}$ of $2\pi/L$) are rescaled by a single factor; target selects what is held fixed:

  • :band (default) — the band's own energy $\tfrac12\langle\lvert\cdot\rvert^{2}\rangle_{\mathrm{band}} = \texttt{energy}$ (band kinetic energy for the velocity, band variance for the scalar $\varphi$); the total energy then floats, oscillating slowly about its mean as the band feeds the cascade.
  • :total — the band is rescaled to absorb the whole-field deficit so the total energy $\tfrac12\langle\lvert\cdot\rvert^{2}\rangle = \texttt{energy}$, which directly pins $u'$ and hence $\mathrm{Re}_\lambda$. If the out-of-band energy alone exceeds energy, the band is zeroed (the closest reachable state).

Rescaling preserves the divergence-free constraint either way.

source
GBGIsotropicTurbulence.Forcing.ConstantPower — Type
ConstantPower(ops; power, lowest_shell = 1, highest_shell = 2)

Constant-power forcing: a banded linear forcing $f = A\,\mathbf{u}$ whose rate is set each step so the energy-injection rate $\langle\mathbf{u}\cdot f\rangle = A\,(2E_{\mathrm{band}})$ equals the target $\varepsilon = \texttt{power}$ — i.e. $A = \varepsilon / (2E_{\mathrm{band}})$ with $E_{\mathrm{band}} = \tfrac12\langle\lvert\cdot\rvert^{2}\rangle_{\mathrm{band}}$ of the start-of-step field. The rate is folded into the integrating factor; like Linear, it preserves a solenoidal velocity.

source
GBGIsotropicTurbulence.Forcing.ForcingSpec — Type
ForcingSpec

A deferred forcing. The operator-free keyword constructors — Linear(; rate), ConstantPower(; power), BandRescaling(; energy), and StochasticOU(; variance, correlation_time) — return a ForcingSpec capturing the parameters; it is materialised into the concrete AbstractForcing once the SpectralOperators exist (done for you by Simulation). A forcing argument therefore accepts either a ready-built AbstractForcing (from the ops-taking constructor) or a ForcingSpec.

source
GBGIsotropicTurbulence.Forcing.Linear — Type
Linear(ops; rate, lowest_shell = 1, highest_shell = 2)

Linear (negative-damping) forcing $f = A\,\mathbf{u}$ in a low-wavenumber band (Lundgren-type), with the fixed rate $A = \texttt{rate}$ on shells $\texttt{lowest\_shell} \le \kappa \le \texttt{highest\_shell}$. The rate is folded into the integrating factor (exact for the linear term), so the forced band modes grow at net rate $A - \nu\lvert\boldsymbol{\kappa}\rvert^{2}$. A positive rate injects energy.

GBGIsotropicTurbulence.Forcing.NoForcing — Type
NoForcing()

The unforced case: both hooks do nothing (a freely decaying field).

GBGIsotropicTurbulence.Forcing.StochasticOU — Type
StochasticOU(ops; variance, correlation_time, lowest_shell = 1, highest_shell = 2, seed = 0)

Stochastic (Eswaran–Pope) forcing: each forced Fourier mode in the band ($\texttt{lowest\_shell} \le \kappa \le \texttt{highest\_shell}$) carries an independent complex Ornstein–Uhlenbeck process, advanced once per step by the exact transition

\[\hat f \leftarrow \theta\,\hat f + \sqrt{\sigma^{2}(1-\theta^{2})}\;\xi, \qquad \theta = \exp(-\Delta t / T_L),\]

with correlation time $T_L = \texttt{correlation\_time}$, stationary forcing variance $\sigma^{2} = \texttt{variance}$ (the stationary $\langle\lvert f\rvert^{2}\rangle$), and $\xi$ a unit-variance, band-limited random field. The increment $\xi$ is generated as a real physical field, transformed, and band-limited — guaranteeing a valid real field with no Hermitian-symmetry bookkeeping — and, when forcing the velocity (a vector field), Leray-projected so the forcing is divergence-free. The frozen $\hat f$ is added to the right-hand side at each stage (see forcing_source!), so it integrates at the scheme's order.

The same type forces either the velocity or the scalar $\varphi$: it adapts to the field it is given (a vector or scalar state, projected only for the velocity), allocated on first use.

Note

The random increment is generated host-side each step; on the GPU this is a portability-first choice, not yet a performance-tuned one.

GBGIsotropicTurbulence.Forcing.apply_forcing! — Method
apply_forcing!(forcing, field, ops, scratch) -> field

Apply a post-step forcing to field (a velocity or scalar $\varphi$ field in spectral representation) in place, using the spectral scratch buffer. The default does nothing; see BandRescaling.

source
GBGIsotropicTurbulence.Forcing.forcing_rate! — Method
forcing_rate!(forcing, rate, field, ops, ws) -> Bool

For a forcing linear in the field, fill the real per-mode rate array rate with $A(\boldsymbol{\kappa})$ (the forcing $f = A\,\texttt{field}$) and return true; the integrator folds it into the integrating factor as $\exp\!\big((A(\boldsymbol{\kappa}) - D\lvert\boldsymbol{\kappa}\rvert^{2})\,\tau\big)$. Return false (the default) when the forcing contributes no linear rate. field is the start-of-step field in spectral representation.

source
GBGIsotropicTurbulence.Forcing.forcing_source! — Method
forcing_source!(forcing, nonlinear, ops, ws) -> nonlinear

Add an additive forcing source to the de-aliased nonlinear-term buffer nonlinear at each Runge–Kutta stage (the source is held fixed over the step, so it integrates at the scheme's order). The default does nothing; see StochasticOU.

source
GBGIsotropicTurbulence.Forcing.prepare_forcing! — Method
prepare_forcing!(forcing, field, ops, ws, dt) -> nothing

Update a forcing's internal state once per step, before the Runge–Kutta stages, from the start-of-step field (in spectral representation) and the timestep dt. The default does nothing; the stochastic forcing advances its Ornstein–Uhlenbeck process here (see StochasticOU).
