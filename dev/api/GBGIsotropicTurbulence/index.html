GBGIsotropicTurbulence.GBGIsotropicTurbulence — Module
GBGIsotropicTurbulence

Tools for simulating and analysing homogeneous isotropic turbulence on three-dimensional periodic domains: a velocity field and a single passive scalar, each optionally forced, advanced by a choice of integrating-factor time-stepping scheme, with Lagrangian particle tracking and Eulerian + Lagrangian statistics.

Built on GBGPeriodicFields.

The GBG part in the name comes from the city of Göteborg (Gothenburg, Sweden), where the primary development took place.
