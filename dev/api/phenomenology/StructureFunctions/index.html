GBGIsotropicTurbulence.Phenomenology.StructureFunctions — Module
Phenomenology.StructureFunctions

Inertial-range structure-function laws — parametrizations of the longitudinal velocity structure function $D_{L\dots}(r)$ and the mixed velocity–scalar structure function $\langle\delta u_L\,(\delta\varphi)^2\rangle$ (Yaglom), evaluated by structure_function.

  • Kolmogorov1941 — the K41 inertial-range laws: the exact 4/5 law, the 2/3 law, and the self-similar exponents (via scaling_exponent).
  • Kolmogorov1962 / SheLeveque1994 — the K62 log-normal and She–Lévêque intermittency models: the anomalous scaling exponents $\zeta_p$ (via scaling_exponent).
  • Yaglom1949 — the exact 4/3 law for the mixed velocity–scalar structure function.
  • Lundgren2002 — the finite-Reynolds-number correction to the 4/5 law.

GBGIsotropicTurbulence.Phenomenology.StructureFunctions.StructureFunction — Type
StructureFunction <: TurbulenceLaw

Supertype of the inertial-range structure-function laws — parametrizations of the longitudinal velocity moments $D_{L\dots}(r) = \langle(\delta u_L)^p\rangle$ (the $p$-th moment of the longitudinal velocity increment across a separation $r$) and the mixed velocity–scalar moment $\langle\delta u_L\,(\delta\varphi)^2\rangle$ (Yaglom1949), evaluated by structure_function.

GBGIsotropicTurbulence.Phenomenology.StructureFunctions.Kolmogorov1941 — Type
Kolmogorov1941(; C₂ = 2.0)

The Kolmogorov (1941) inertial-range structure-function laws for the longitudinal velocity increment $\delta u_L$. structure_function(law, r, fp; order) returns:

  • order = 2 — the 2/3 law $D_{LL}(r) = C_2\,(\varepsilon r)^{2/3}$, the second-order increment; the constant C₂ ≈ 2.0 is empirical (default 2.0).
  • order = 3 — the 4/5 law $D_{LLL}(r) = -\tfrac{4}{5}\,\varepsilon r$, the third-order increment; this one is exact (a consequence of the Kármán–Howarth–Monin relation), carrying no free constant.

Both hold in the inertial range $\eta \ll r \ll L$. The state fp (a FlowParameters) supplies the dissipation rate $\varepsilon$; any other order throws (K41 fixes only these two longitudinal moments universally). Its scaling_exponent(law, order) gives the self-similar K41 exponent $\zeta_p = p/3$.

GBGIsotropicTurbulence.Phenomenology.StructureFunctions.Kolmogorov1962 — Type
Kolmogorov1962(; μ = 0.25)

The Kolmogorov (1962) log-normal (refined-similarity) intermittency model. Its scaling_exponent(law, order) gives

\[\zeta_p = \frac{p}{3} - \frac{\mu}{18}\,p\,(p - 3),\]

with μ the intermittency exponent ($\approx 0.25$). Like SheLeveque1994 it is exact at $\zeta_3 = 1$ and bends below the self-similar $p/3$ for $p > 3$, but as a quadratic in $p$ (the log-normal ansatz) rather than She–Lévêque's log-Poisson form.

GBGIsotropicTurbulence.Phenomenology.StructureFunctions.SheLeveque1994 — Type
SheLeveque1994()

The She–Lévêque (1994) intermittency model for the inertial-range scaling exponents. Its scaling_exponent(law, order) gives the anomalous exponent

\[\zeta_p = \frac{p}{9} + 2\left[1 - \left(\tfrac{2}{3}\right)^{p/3}\right]\]

of the $p$-th-order longitudinal structure function $D_{L\dots}(r) \sim r^{\zeta_p}$. It is parameter-free, exact at $\zeta_3 = 1$ (the 4/5 law), and bends below the self-similar $p/3$ for $p > 3$ — the signature of small-scale intermittency. It predicts exponents, not amplitudes, so it implements scaling_exponent but not structure_function.

GBGIsotropicTurbulence.Phenomenology.StructureFunctions.Yaglom1949 — Type
Yaglom1949()

The Yaglom (1949) "4/3 law" — the exact inertial-range scaling of the mixed third-order velocity–scalar structure function, the passive-scalar analogue of the 4/5 law (a consequence of the Yaglom relation); it carries no free constant. Its classical $-\tfrac{4}{3}$ coefficient is stated for the dissipation rate of the half-variance $\tfrac12\langle\varphi^2\rangle$, namely $\varkappa\langle\lvert\nabla\varphi\rvert^2\rangle$ — just as the 4/5 law pairs with $\varepsilon = \nu\langle\lvert\boldsymbol\omega\rvert^2\rangle$, the dissipation of the half-energy $k$. This package's $\varepsilon_\varphi = 2\varkappa\langle\lvert\nabla\varphi\rvert^2\rangle$ (scalar_dissipation) is the full-variance rate, twice that, so in these variables the law is

\[\langle\delta u_L\,(\delta\varphi)^2\rangle(r) = -\tfrac{2}{3}\,\varepsilon_\varphi\,r.\]

structure_function(law, r, fp; order = 3) returns it, reading the scalar dissipation $\varepsilon_\varphi$ (fp.scalar_dissipation, which must be set); any other order throws.

GBGIsotropicTurbulence.Phenomenology.StructureFunctions.Lundgren2002 — Type
Lundgren2002()

The finite-Reynolds-number correction to the 4/5 law for the third-order longitudinal velocity structure function,

\[D_{LLL}(r) = -\left(\tfrac{4}{5} - \frac{8.45}{\mathrm{Re}_\lambda^{2/3}}\right)\varepsilon\,r,\]

which relaxes to the exact $-\tfrac45\varepsilon r$ of Kolmogorov1941 as $\mathrm{Re}_\lambda \to \infty$ — turbulence at a finite Reynolds number never quite reaches the asymptotic 4/5 slope (Lundgren 2002; Sagaut & Cambon 2018, Table 4.5). structure_function(law, r, fp; order = 3) returns it, reading $\mathrm{Re}_\lambda$ from fp via taylor_reynolds; any other order throws.
