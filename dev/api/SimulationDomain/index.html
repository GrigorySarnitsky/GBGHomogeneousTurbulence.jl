SimulationDomain

GBGIsotropicTurbulence.SimulationDomain — Module
SimulationDomain

The discretized periodic box a run lives on — the reusable, read-only frame:

  • FixedDomain — the fixed, unsheared cubic box (grid, transform plans, spectral multipliers, and the lazy $\lvert\boldsymbol{\kappa}\rvert^2$ and dealias kernels).
  • DealiasingStrategy — the aliasing-control strategy, TwoThirds, HouLi, or PhaseShift, and the cutoff it sets, max_wavenumber.
  • new_vector_field_spectral, new_vector_field_physical, new_scalar_field_spectral, new_scalar_field_physical, new_tensor_field_spectral, new_tensor_field_physical — the field allocators (a zeroed field of the named kind and representation, on the domain's backend and element type).
  • truncate_to_band! — apply the dealias kernel to a field in spectral representation, in place.
  • write_domain / read_domain — the domain's HDF5 persistence: one self-describing group of its defining parameters (available once HDF5 is loaded).

Precision and backend enter here and flow everywhere from here.

The discretized box

The reusable, read-only frame every buffer is allocated from — the FixedDomain, a fixed, unsheared periodic cube (a sheared frame is deferred).

GBGIsotropicTurbulence.SimulationDomain.FixedDomain — Type
FixedDomain(; grid_points_per_axis, side_length,
            dealiasing, element_type, array_type)

The discretized periodic box a run lives on — the reusable, read-only frame: a cube of side length side_length sampled with grid_points_per_axis points along each axis, holding everything the pseudospectral method needs on that box.

Arguments

All keyword, all required:

  • grid_points_per_axis — grid points $N$ along each axis (the box is $N^{3}$).
  • side_length — the physical side length $L$ (the box is $[0,L)^{3}$).
  • dealiasing — the dealiasing strategy: TwoThirds (the sharp $2/3$ rule) and HouLi (the smooth Hou–Li filter) apply truncate_to_band! as a coefficientwise multiply, while PhaseShift averages a half-cell-displaced evaluation (exact, keeping a fuller band at $2\times$ the transforms). It controls the aliasing of the quadratic nonlinearity and sets the advective-CFL ceiling through recommended_cfl.
  • element_type — the real element type (Float32 is GPU-friendly).
  • array_type — the storage backend: Array (CPU) or CuArray / ROCArray (GPU).

Examples

A default box, and one that keeps a wider band on the same grid:

domain = FixedDomain(; grid_points_per_axis = 128, side_length = 2π,
                       dealiasing = TwoThirds(), element_type = Float64, array_type = Array)

wide = FixedDomain(; grid_points_per_axis = 128, side_length = 2π,
                     dealiasing = HouLi(), element_type = Float64, array_type = Array)
Nothing here defaults

The grid, the box, the aliasing control, the precision and the storage backend are each a decision about the run; the Simulation convenience constructor supplies them for you when you do not want to make them.

Fields

The machinery types below are GBGPeriodicFields objects, each linked to its own documentation.

  • grid, layout — the Grid3D and its RealFourierLayout memory layout.
  • velocity_plans, scalar_plans — the real-to-complex FieldTransformPlans for the velocity and the scalar, built with the domain because the time loop transforms both every step.
  • tensor_plans_memo — where the rank-2 plans go once tensor_plans builds them, which it does on the first rank-2 transform rather than here. Read them through that function, never this field.
  • multipliers — the FieldSpectralMultipliers, the spectral first-derivative operators.
  • squared_wavenumber_kernel — $\lvert\boldsymbol{\kappa}\rvert^{2}$ as a lazy RadialKernel (in spectral representation $-\nabla^{2}$ acts as multiplication by it) — the weight that turns a Parseval sum into a mean-square-gradient (Dirichlet-energy) sum, which the weighted spectral reductions take; never materialized — evaluated per mode from the multipliers, with no array allocated.
  • unit_kernel — the constant weight $1$, the same lazy form: the identity weight that lets a plain variance join a multi-weight fused reduction (one traversal answering several weighted sums at once), since $\langle f, 1\cdot f\rangle$ is the mean square — the variance of a mean-zero field.
  • storage_family — the storage family (Array / CuArray / ROCArray) the run's arrays live in — a type, not an array; the allocators hand it to GBGPeriodicFields' family-taking field constructors.
  • dealias, dealiasing — the dealias kernel (a compressed SpectralKernel, evaluated per mode) and the DealiasingStrategy that built it.

Dealiasing strategies

The aliasing-control strategy passed to FixedDomain — the supertype, then the sharp $2/3$-rule truncation, the smooth Hou–Li filter, and the exact half-cell phase-shift with spherical truncation.

GBGIsotropicTurbulence.SimulationDomain.DealiasingStrategy — Type
DealiasingStrategy

How the aliasing of the quadratic nonlinearity is controlled. A FixedDomain is built with one; it fixes the domain.dealias kernel and, through recommended_cfl, the advective-CFL ceiling. They come in two families: a mask strategy acts on the assembled product alone, while a shift strategy also changes how that product is evaluated. Concrete strategies: TwoThirds (the sharp $2/3$ rule, a mask), HouLi (the smooth Hou–Li filter, a mask), and PhaseShift (the half-cell shift-average, a shift, truncated spherically at $\tfrac{2\sqrt{2}}{3}\kappa_{\mathrm{Ny}}$). The Simulation constructor that builds a whole run from a few keywords defaults to TwoThirds.

source
GBGIsotropicTurbulence.SimulationDomain.TwoThirds — Type
TwoThirds()

The sharp isotropic $2/3$-rule truncation of Orszag (1971, On the elimination of aliasing in finite-difference schemes by filtering high-wavenumber components, J. Atmos. Sci. 28, 1074). Keep the modes $\kappa \le \kappa_{\max} = \tfrac{2}{3}\kappa_{\mathrm{Ny}}$ and zero the rest, where $\kappa_{\mathrm{Ny}} = \tfrac{N}{2}\cdot\tfrac{2\pi}{L}$ is the Nyquist wavenumber and $\kappa_{\max}$ the dealiased maximum — two-thirds of the way out to Nyquist. Exact dealiasing of the quadratic nonlinearity, with the narrowest retained band of the three and no taper to evaluate.

source
GBGIsotropicTurbulence.SimulationDomain.HouLi — Type
HouLi(; order = 36, strength = nothing)

The smooth spectral filter of Hou & Li (2007, Computing nearly singular solutions using pseudo-spectral methods, J. Comput. Phys. 226, 379–397). Each mode is multiplied by the transfer function $\exp\!\bigl(- \texttt{strength} (\kappa/\kappa_{\mathrm{Ny}})^{\texttt{order}}\bigr)$, applied isotropically in $\kappa$, with $\kappa_{\mathrm{Ny}} = \tfrac{N}{2}\cdot\tfrac{2\pi}{L}$ the Nyquist wavenumber. It keeps more modes than the $2/3$ rule but only damps aliasing rather than removing it exactly — a stabilization.

The order sets the sharpness of the spectral roll-off (higher is closer to a sharp cutoff). The strength sets the damping at the Nyquist mode, which is multiplied by $\mathrm{e}^{-\texttt{strength}}$. By default (strength = nothing) strength is chosen for the domain's element type as $-\log$ of its machine epsilon — $\approx 36$ for Float64, $\approx 16$ for Float32 — so the Nyquist mode always damps to that precision's machine epsilon; pass an explicit strength to override.

Because the filter retains energy out to the Nyquist wavenumber it takes a proportionally smaller CFL step than the $2/3$ rule — handled automatically by recommended_cfl.

Fields

The plain constructor HouLi(order, strength) takes the two fields directly:

  • order — the exponent of the spectral roll-off.
  • strength — the damping at the Nyquist mode, or nothing for the element-type default described above.

GBGIsotropicTurbulence.SimulationDomain.PhaseShift — Type
PhaseShift()

Phase-shift dealiasing — Patterson & Orszag (1971, Spectral calculations of isotropic turbulence: efficient removal of aliasing interactions, Phys. Fluids 14, 2538–2541), combined with the spherical truncation of Rogallo (1981) — Numerical experiments in homogeneous turbulence, NASA TM-81315 (no DOI): assemble each quadratic nonlinear term on the grid and on a grid displaced by half a cell, average the two, and truncate spherically at $\kappa_{\max} = \tfrac{\sqrt{2}}{3}N\cdot\tfrac{2\pi}{L} = \tfrac{2\sqrt{2}}{3}\kappa_{\mathrm{Ny}}$ (with $\kappa_{\mathrm{Ny}} = \tfrac{N}{2}\cdot\tfrac{2\pi}{L}$ the Nyquist wavenumber).

The half-cell average cancels the aliasing images that wrap in an odd number of axes — the spurious spectral replicas the under-resolved quadratic product folds back into the resolved band — and the spherical cutoff removes the surviving two-axis images. It dealiases the quadratic exactly while keeping the resolved band out to $\tfrac{2\sqrt{2}}{3}\kappa_{\mathrm{Ny}} \approx 0.94 \kappa_{\mathrm{Ny}}$ — a factor $\sqrt{2}$ further than the TwoThirds rule's $\tfrac{2}{3}\kappa_{\mathrm{Ny}}$ ($\approx 2.8\times$ the modes in the retained sphere).

Use it when the recovered bulk of that discarded top third — out to $\approx 0.94\kappa_{\mathrm{Ny}}$, never the Nyquist-adjacent remainder — is worth the price: a second nonlinear-term transform per stage ($2\times$ the transforms) and the displaced-evaluation scratch (a field-scale spectral-representation buffer per phase-shifted term). Because it retains energy out to $\tfrac{2\sqrt{2}}{3}\kappa_{\mathrm{Ny}}$ it takes a proportionally smaller advective-CFL step than the $2/3$ rule — handled automatically by recommended_cfl.

A half-cell shift attenuates the Nyquist mode

A half-cell displacement cannot translate the Nyquist mode of a real field — it attenuates it by $\cos(\pi h_a/\Delta x_a)$, which vanishes at half a cell. This never bites here: the spherical cutoff at $\tfrac{2\sqrt{2}}{3}\kappa_{\mathrm{Ny}} < \kappa_{\mathrm{Ny}}$ leaves the field with no Nyquist content to mistranslate.

source

The dealiasing cutoff it sets — the highest wavenumber the run treats as resolved signal, and the resolution criterion $\kappa_{\max}\eta$ a run is built to meet.

GBGIsotropicTurbulence.SimulationDomain.max_wavenumber — Function
max_wavenumber(domain)

The highest wavenumber magnitude domain (a FixedDomain) treats as resolved signal — the dealiasing cutoff

\[\kappa_{\max} = f \frac{N}{2} \frac{2\pi}{L},\]

with $N$ the grid points per side, $L$ the box side, $f$ the retained-Nyquist fraction of the DealiasingStrategy ($2/3$ for TwoThirds, $1$ for HouLi, $\tfrac{2\sqrt{2}}{3}$ for PhaseShift). For the sharp strategies the cutoff sits strictly below the grid Nyquist $\tfrac{N}{2}\tfrac{2\pi}{L}$ — they zero the modes above it each step. HouLi is the exception its $f = 1$ implies: its cutoff is the Nyquist, so there is no band above to zero, and it instead damps modes as they approach it (to machine epsilon at Nyquist) — so under HouLi every representable mode counts as resolved signal, and $\kappa_{\max}$ bounds the representable band rather than separating kept from damped content.

The cutoff fixes both the advective-CFL step (recommended_cfl) and the resolution criterion $\kappa_{\max}\eta$ — with $\eta$ the Kolmogorov (dissipation) microscale — that a run is set up to meet.

Band truncation

Restrict a field in spectral representation to the retained band, in place, by the domain's low-pass kernel. Under PhaseShift this is only part of the dealiasing — the averaging of two displaced evaluations is the other half, and the generator performs it where it assembles the product.

GBGIsotropicTurbulence.SimulationDomain.truncate_to_band! — Function
truncate_to_band!(field, domain)

Apply the run's dealias low-pass kernel domain.dealias — domain a FixedDomain — to field in place: a coefficientwise multiply that controls the aliasing of the quadratic nonlinearity. The kernel is whatever the run's DealiasingStrategy built: the sharp $2/3$ cutoff (TwoThirds, exact dealiasing), the smooth HouLi filter (which only damps the aliasing), or the spherical $\tfrac{2\sqrt{2}}{3}\kappa_{\mathrm{Ny}}$ truncation (PhaseShift). The field may be a vector or scalar field in spectral representation. Returns field.

This verb truncates; under PhaseShift that is half the dealiasing

For TwoThirds this call is the whole of it; for HouLi the taper damps the aliases rather than removing them. Under PhaseShift it is only the second half — a product assembled without the displaced-evaluation average stays aliased, so a hand-built assembly must pair the two as the generator does.

Persistence

The domain's HDF5 persistence — its defining parameters as one self-describing group, available once HDF5 is loaded.

GBGIsotropicTurbulence.SimulationDomain.write_domain — Function
write_domain(parent::HDF5.H5DataStore, name::AbstractString, domain::FixedDomain)

Write the FixedDomain domain under parent as one self-describing HDF5 group — its defining parameters (the grid points per axis, the side length, the element type, and the dealiasing strategy with its settings), never the derived machinery (transform plans, multipliers, kernels), which the reader rebuilds. Available once the HDF5 package is loaded; opening and closing the file is the caller's job.

The arguments are:

  • parent — the open HDF5 file or group to write under.
  • name — the created group's name.
  • domain — the FixedDomain to record.

Returns the created group. Reload with read_domain.

source
GBGIsotropicTurbulence.SimulationDomain.read_domain — Function
read_domain(parent::HDF5.H5DataStore, name::AbstractString;
            array_type = Array) -> FixedDomain

Rebuild a FixedDomain from the group write_domain wrote — the recorded parameters through the ordinary constructor, so the transform plans, multipliers and kernels are rebuilt, never read. A group that was not written by write_domain, or was written by a newer schema version, is refused with an ArgumentError. Available once the HDF5 package is loaded.

The arguments are:

  • parent — the open HDF5 file or group holding the domain group.
  • name — the group's name.
  • array_type = Array — the storage backend the rebuilt domain lives on. The backend is deliberately not taken from the file: a checkpoint written on one backend loads on any other, so the reader, not the writer, names it.
