Notation

The symbols used throughout the docstrings and the design documents, with the code object each one denotes. All mathematics is rendered LaTeX; a code identifier always appears in backticks and never inside a math span. This page is the single reference — a docstring introduces a symbol on first use and need not repeat the convention.

The physical conventions are standard turbulence usage — see Pope (2000), Turbulent Flows; the field and spectral conventions follow GBGPeriodicFields, a direct dependency.

Conventions

ConceptSymbolConvention
Imaginary unit$\mathrm{i}$Upright, always — never bare italic $i$, never $\imath$. Writing it upright frees $i$ for use as an index.
Indices$i, j, a, \dots$Italic, taken in order. A repeated index within a term is summed over the three components $1,2,3$ (Einstein convention).
Spatial average$\langle \cdot \rangle$The box average $\frac{1}{\lvert\Omega\rvert}\int_\Omega(\cdot)\,\mathrm{d}\boldsymbol{x}$ over the periodic domain $\Omega$ — the single-realization estimate of the homogeneous ensemble average (exact only in the ergodic, infinite-box limit; at a finite box it retains the large-scale statistical fluctuation).
Spectral representation$\hat f$The field $f$ in spectral (Fourier) representation, to_spectral(f). A field is one physical object; physical and spectral are two representations of it.
Wavenumber clash$\boldsymbol{\kappa}$ / $\kappa$ / $k$Kept distinct: bold $\boldsymbol{\kappa}$ is the wavenumber vector, $\kappa = \lvert\boldsymbol{\kappa}\rvert$ its magnitude (the spectrum coordinate), and italic scalar $k$ is the turbulent kinetic energy.

Vocabulary

The page above fixes one symbol per physical concept. This section does the same for the package's operational words — the ones that name how a run is organized rather than what it computes. Each is used throughout the docstrings, and each means exactly this and nothing looser.

TermMeaning
iterationone advance of the run: a step! followed by the deposit! that closes it. Wider than a step, which is only the first half, and than a stage, which is one Runge–Kutta substep inside it.
depositto write an observable into the cache and mark the moment it belongs to. The closing deposit is the one that ends an iteration; nothing is ever written to the cache on a read.
slotone storage place in the ObservablesCache — an array or a number, together with the epoch its value belongs to.
epocha counter of changes to the state, one per dynamical factor (the fields, the tracer positions). A slot is readable exactly when its own epoch equals the counter it depends on. Not an iteration number: an announced out-of-band mutation advances an epoch without advancing the clock.
registerstorage a component computes one value into and overwrites at the next, holding nothing a reader should trust in between. A cache slot doubles as its producer's register mid-iteration, which is why a cached field is meaningful only between iterations.
front doorthe Simulation constructor that builds every component from a few keywords, as against assembling the pieces yourself.
observationthe callback a run is driven by: it reads the run once per iteration and its return decides whether to continue.
resolvedin ResolvedFields and ResolvedGenerator, made concrete as one value — not the numerical sense of "resolved by the grid", which this package writes out in full wherever it is meant.
