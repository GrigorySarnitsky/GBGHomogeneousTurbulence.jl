SimulationDomain

GBGIsotropicTurbulence.SimulationDomain — Module
SimulationDomain

The discretized periodic box a run lives on — the reusable, read-only frame:

  • FixedDomain — the fixed, unsheared cubic box (grid, transform plans, spectral multipliers, squared-wavenumber field, dealias kernel).
  • DealiasingStrategy — the aliasing-control strategy, TwoThirds, HouLi, or PhaseShift, and the cutoff it sets, max_wavenumber.
  • spectral_vector, scalar_spectral, … — the field-sized scratch allocators.
  • dealias! — apply the dealias kernel to a field in spectral representation, in place.

Precision and backend enter here and flow everywhere from here.

The discretized box

The reusable, read-only frame every buffer is allocated from — the FixedDomain, a fixed, unsheared periodic cube (a sheared frame is deferred).

GBGIsotropicTurbulence.SimulationDomain.FixedDomain — Type
FixedDomain(grid_points_per_axis, side_length;
            dealiasing, element_type, array_type)

The discretized periodic box a run lives on — the reusable, read-only frame: a cube of side length side_length sampled with grid_points_per_axis points along each axis, holding everything the pseudospectral method needs on that box.

Arguments

FixedDomain carries no defaults — every argument is explicit; the Simulation front door supplies the run-layer defaults (side_length = 2π, dealiasing = TwoThirds(), element_type = Float64, array_type = Array).

  • grid_points_per_axis — grid points $N$ along each axis (the box is $N^{3}$).
  • side_length — the physical side length $L$ (the box is $[0,L)^{3}$).
  • dealiasing — the dealiasing strategy: TwoThirds (the sharp $2/3$ rule) and HouLi (the smooth Hou–Li filter) apply dealias! as a coefficientwise multiply, while PhaseShift averages a half-cell-displaced evaluation (exact, keeping a fuller band at $2\times$ the transforms). It controls the aliasing of the quadratic nonlinearity and sets the advective-CFL ceiling through recommended_cfl.
  • element_type — the real element type (Float32 is GPU-friendly).
  • array_type — the storage backend: Array (CPU) or CuArray / ROCArray (GPU).

Fields

  • grid, layout — the Grid3D and its RealFourierLayout memory layout.
  • velocity_plans, scalar_plans, tensor_plans — the real-to-complex FieldTransformPlans, one per field rank: the velocity (a vector field), the scalar (a scalar field), and the rank-2 strain tensor the derivative-skewness diagnostic needs.
  • multipliers — the FieldSpectralMultipliers, the spectral first-derivative operators.
  • squared_wavenumber, squared_wavenumber_kernel — $\lvert\boldsymbol{\kappa}\rvert^{2}$ (in spectral representation $-\nabla^{2}$ acts as multiplication by it), kept both as a real array and as a scalar-field kernel for weighted spectral reductions.
  • dealias, dealiasing — the dealias kernel and the DealiasingStrategy that built it.

Dealiasing strategies

The aliasing-control strategy passed to FixedDomain — the supertype, then the sharp $2/3$-rule default, the smooth Hou–Li filter, and the exact half-cell phase-shift with spherical truncation.

GBGIsotropicTurbulence.SimulationDomain.DealiasingStrategy — Type
DealiasingStrategy

How the aliasing of the quadratic nonlinearity is controlled. A FixedDomain is built with one; it fixes the domain.dealias kernel and, through recommended_cfl, the advective-CFL ceiling. Concrete strategies: TwoThirds (the sharp $2/3$ rule, the default), HouLi (the smooth Hou–Li filter), and PhaseShift (the half-cell shift-average with spherical $2\sqrt2/3$ truncation).

source
GBGIsotropicTurbulence.SimulationDomain.TwoThirds — Type
TwoThirds()

The sharp isotropic $2/3$-rule truncation: keep the modes $\kappa \le \kappa_{\max} = \tfrac{2}{3}\kappa_{\mathrm{Ny}}$ and zero the rest, where $\kappa_{\mathrm{Ny}} = \tfrac N2\cdot\tfrac{2\pi}{L}$ is the Nyquist wavenumber and $\kappa_{\max}$ the dealiased maximum — two-thirds of the way out to Nyquist. Exact dealiasing of the quadratic nonlinearity, and the lean, GPU-friendly default.

source
GBGIsotropicTurbulence.SimulationDomain.HouLi — Type
HouLi(; order = 36, strength = nothing)

The smooth Hou–Li spectral filter, transfer function $\exp\!\big(- \texttt{strength} (\kappa/\kappa_{\mathrm{Ny}})^{\texttt{order}}\big)$, with $\kappa_{\mathrm{Ny}} = \tfrac N2\cdot\tfrac{2\pi}{L}$ the Nyquist wavenumber. The order sets the sharpness of the spectral roll-off (higher is closer to a sharp cutoff); the strength sets the damping at the Nyquist mode, which is multiplied by $\mathrm{e}^{-\texttt{strength}}$. By default (strength = nothing) strength is chosen for the domain's element type as $-\log$ of its machine epsilon — $\approx 36$ for Float64, $\approx 16$ for Float32 — so the Nyquist mode always damps to that precision's machine epsilon; pass an explicit strength to override. It keeps more modes than the $2/3$ rule but only damps aliasing rather than removing it exactly — a stabilization, hence an opt-in, not the default. Applied isotropically in $\kappa$. Because it retains energy out to the Nyquist wavenumber it takes a proportionally smaller CFL step than the $2/3$ rule — handled automatically by recommended_cfl. The smooth spectral filter is due to Hou & Li (2007).

source
GBGIsotropicTurbulence.SimulationDomain.PhaseShift — Type
PhaseShift()

Phase-shift dealiasing: assemble each quadratic nonlinear term on the grid and on a grid displaced by half a cell, average the two, and truncate spherically at $\kappa_{\max} = \tfrac{\sqrt2}{3}N\cdot\tfrac{2\pi}{L} = \tfrac{2\sqrt2}{3}\kappa_{\mathrm{Ny}}$ (with $\kappa_{\mathrm{Ny}} = \tfrac N2\cdot\tfrac{2\pi}{L}$ the Nyquist wavenumber). The half-cell average cancels the aliasing images that wrap in an odd number of axes; the spherical cutoff removes the surviving two-axis images. It dealiases the quadratic exactly while keeping the resolved band out to $\tfrac{2\sqrt2}{3}\kappa_{\mathrm{Ny}} \approx 0.94 \kappa_{\mathrm{Ny}}$ — a factor $\sqrt2$ further than the TwoThirds rule's $\tfrac{2}{3}\kappa_{\mathrm{Ny}}$ ($\approx 2.8\times$ the modes in the retained sphere).

Use it when that top third of wavenumbers is worth the price: a second nonlinear-term transform per stage ($2\times$ the transforms) and the displaced-evaluation scratch (a spectral field per phase-shifted term). Opt-in, not the default. Because it retains energy out to $\tfrac{2\sqrt2}{3}\kappa_{\mathrm{Ny}}$ it takes a proportionally smaller advective-CFL step than the $2/3$ rule — handled automatically by recommended_cfl.

The Nyquist mistranslation does not bite

A half-cell displacement cannot translate the Nyquist mode of a real field — it attenuates it by $\cos(\pi h_a/\Delta x_a)$, which vanishes at half a cell. This never bites here: the spherical cutoff at $2\sqrt2/3 \kappa_{\mathrm{Ny}} < \kappa_{\mathrm{Ny}}$ leaves the field with no Nyquist content to mistranslate.

Phase-shift dealiasing follows Patterson & Orszag (1971); the combination with spherical truncation is Rogallo (1981).

The dealiasing cutoff it sets — the highest wavenumber the domain evolves, and the resolution criterion $\kappa_{\max}\eta$ a run is built to meet.

GBGIsotropicTurbulence.SimulationDomain.max_wavenumber — Function
max_wavenumber(domain)

The highest wavenumber magnitude that domain actually evolves — the dealiasing cutoff

\[\kappa_{\max} = f \frac N2 \frac{2\pi}{L},\]

with $N$ the grid points per side, $L$ the box side, and $f$ the retained-Nyquist fraction of the DealiasingStrategy ($2/3$ for TwoThirds, $1$ for HouLi, $2\sqrt2/3$ for PhaseShift). It is the cutoff the dealiasing sets — not the grid Nyquist $\tfrac N2\tfrac{2\pi}{L}$ itself; the modes above it are zeroed each step. It fixes both the advective-CFL step (recommended_cfl) and the resolution criterion $\kappa_{\max}\eta$ that a run is set up to meet.

Dealias filtering

Apply the domain's dealias low-pass kernel to a spectral field in place.

GBGIsotropicTurbulence.SimulationDomain.dealias! — Function
dealias!(field, domain)

Apply the run's dealias low-pass domain.dealias to field in place — a coefficientwise multiply that controls the aliasing of the quadratic nonlinearity. The kernel is whatever the run's DealiasingStrategy built: the sharp $2/3$ cutoff (TwoThirds, exact dealiasing), the smooth HouLi filter (which only damps the aliasing), or the spherical $2\sqrt2/3 \kappa_{\mathrm{Ny}}$ truncation (PhaseShift). The field may be a vector or scalar field in spectral representation.
