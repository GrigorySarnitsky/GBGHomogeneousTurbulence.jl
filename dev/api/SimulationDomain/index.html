SimulationDomain

GBGIsotropicTurbulence.SimulationDomain — Module
SimulationDomain

The discretized periodic box a run lives on — the reusable, read-only frame:

  • FixedDomain — the fixed, unsheared cubic box (grid, transform plans, spectral multipliers, and the lazy $\lvert\boldsymbol{\kappa}\rvert^2$ and dealias kernels).
  • DealiasingStrategy — the aliasing-control strategy, TwoThirds, HouLi, or PhaseShift, and the cutoff it sets, max_wavenumber.
  • new_vector_field_spectral, new_vector_field_physical, new_scalar_field_spectral, new_scalar_field_physical, new_tensor_field_spectral, new_tensor_field_physical — the field allocators (a zeroed field of the named kind and representation, on the domain's backend and element type).
  • truncate_to_band! — apply the dealias kernel to a field in spectral representation, in place.

Precision and backend enter here and flow everywhere from here.

The discretized box

The reusable, read-only frame every buffer is allocated from — the FixedDomain, a fixed, unsheared periodic cube (a sheared frame is deferred).

GBGIsotropicTurbulence.SimulationDomain.FixedDomain — Type
FixedDomain(; grid_points_per_axis, side_length,
            dealiasing, element_type, array_type)

The discretized periodic box a run lives on — the reusable, read-only frame: a cube of side length side_length sampled with grid_points_per_axis points along each axis, holding everything the pseudospectral method needs on that box.

Arguments

All keyword, all required:

  • grid_points_per_axis — grid points $N$ along each axis (the box is $N^{3}$).
  • side_length — the physical side length $L$ (the box is $[0,L)^{3}$).
  • dealiasing — the dealiasing strategy: TwoThirds (the sharp $2/3$ rule) and HouLi (the smooth Hou–Li filter) apply truncate_to_band! as a coefficientwise multiply, while PhaseShift averages a half-cell-displaced evaluation (exact, keeping a fuller band at $2\times$ the transforms). It controls the aliasing of the quadratic nonlinearity and sets the advective-CFL ceiling through recommended_cfl.
  • element_type — the real element type (Float32 is GPU-friendly).
  • array_type — the storage backend: Array (CPU) or CuArray / ROCArray (GPU).

Examples

A default box, and one that keeps a wider band on the same grid:

domain = FixedDomain(; grid_points_per_axis = 128, side_length = 2π,
                       dealiasing = TwoThirds(), element_type = Float64, array_type = Array)

wide = FixedDomain(; grid_points_per_axis = 128, side_length = 2π,
                     dealiasing = HouLi(), element_type = Float64, array_type = Array)

Nothing here defaults: the grid, the box, the aliasing control, the precision and the storage backend are each a decision about the run, and the Simulation convenience constructor supplies them for you when you do not want to.

Fields

The machinery types below are GBGPeriodicFields objects, each linked to its own documentation.

  • grid, layout — the Grid3D and its RealFourierLayout memory layout.
  • velocity_plans, scalar_plans, tensor_plans — the real-to-complex FieldTransformPlans, one per field rank: the velocity (a vector field), the scalar (a scalar field), and the rank-2 strain tensor the derivative-skewness diagnostic needs.
  • multipliers — the FieldSpectralMultipliers, the spectral first-derivative operators.
  • squared_wavenumber_kernel — $\lvert\boldsymbol{\kappa}\rvert^{2}$ as a lazy RadialKernel (in spectral representation $-\nabla^{2}$ acts as multiplication by it) — the weight that turns a Parseval sum into a mean-square-gradient (Dirichlet-energy) sum, which the weighted spectral reductions take; never materialized — evaluated per mode from the multipliers, with no array allocated.
  • dealias, dealiasing — the dealias kernel (a compressed SpectralKernel, evaluated per mode) and the DealiasingStrategy that built it.

Dealiasing strategies

The aliasing-control strategy passed to FixedDomain — the supertype, then the sharp $2/3$-rule truncation, the smooth Hou–Li filter, and the exact half-cell phase-shift with spherical truncation.

GBGIsotropicTurbulence.SimulationDomain.DealiasingStrategy — Type
DealiasingStrategy

How the aliasing of the quadratic nonlinearity is controlled. A FixedDomain is built with one; it fixes the domain.dealias kernel and, through recommended_cfl, the advective-CFL ceiling. They come in two families, and the rest of the corpus uses these names: a mask strategy acts on the assembled product alone, while a shift strategy also changes how that product is evaluated. Concrete strategies: TwoThirds (the sharp $2/3$ rule, a mask), HouLi (the smooth Hou–Li filter, a mask), and PhaseShift (the half-cell shift-average, a shift, truncated spherically at $\tfrac{2\sqrt{2}}{3}\kappa_{\mathrm{Ny}}$). Which one a run gets by default is decided by the Simulation constructor that builds a whole run from a few keywords — the front door — and not by this catalogue.

source
GBGIsotropicTurbulence.SimulationDomain.TwoThirds — Type
TwoThirds()

The sharp isotropic $2/3$-rule truncation of Orszag (1971) — On the elimination of aliasing in finite-difference schemes by filtering high-wavenumber components, J. Atmos. Sci. 28, 1074, doi:10.1175/1520-0469(1971)028<1074:OTEOAI>2.0.CO;2. Keep the modes $\kappa \le \kappa_{\max} = \tfrac{2}{3}\kappa_{\mathrm{Ny}}$ and zero the rest, where $\kappa_{\mathrm{Ny}} = \tfrac{N}{2}\cdot\tfrac{2\pi}{L}$ is the Nyquist wavenumber and $\kappa_{\max}$ the dealiased maximum — two-thirds of the way out to Nyquist. Exact dealiasing of the quadratic nonlinearity, with the narrowest retained band of the three and no taper to evaluate.

source
GBGIsotropicTurbulence.SimulationDomain.HouLi — Type
HouLi(; order = 36, strength = nothing)

The smooth spectral filter of Hou & Li (2007) — Computing nearly singular solutions using pseudo-spectral methods, J. Comput. Phys. 226, 379–397, doi:10.1016/j.jcp.2007.04.014. Transfer function $\exp\!\bigl(- \texttt{strength} (\kappa/\kappa_{\mathrm{Ny}})^{\texttt{order}}\bigr)$, with $\kappa_{\mathrm{Ny}} = \tfrac{N}{2}\cdot\tfrac{2\pi}{L}$ the Nyquist wavenumber. The order sets the sharpness of the spectral roll-off (higher is closer to a sharp cutoff); the strength sets the damping at the Nyquist mode, which is multiplied by $\mathrm{e}^{-\texttt{strength}}$. By default (strength = nothing) strength is chosen for the domain's element type as $-\log$ of its machine epsilon — $\approx 36$ for Float64, $\approx 16$ for Float32 — so the Nyquist mode always damps to that precision's machine epsilon; pass an explicit strength to override. (That Float64 value lands on $36$, which the default order also is: Hou & Li's own filter takes both as $36$, and the coincidence is theirs rather than a transcription slip.) It keeps more modes than the $2/3$ rule but only damps aliasing rather than removing it exactly — a stabilization. Applied isotropically in $\kappa$. Because it retains energy out to the Nyquist wavenumber it takes a proportionally smaller CFL step than the $2/3$ rule — handled automatically by recommended_cfl.

Fields

The plain constructor HouLi(order, strength) takes the two fields directly:

  • order — the exponent of the spectral roll-off.
  • strength — the damping at the Nyquist mode, or nothing for the element-type default described above.

GBGIsotropicTurbulence.SimulationDomain.PhaseShift — Type
PhaseShift()

Phase-shift dealiasing — Patterson & Orszag (1971) — Spectral calculations of isotropic turbulence: efficient removal of aliasing interactions, Phys. Fluids 14, 2538–2541, doi:10.1063/1.1693365, combined with the spherical truncation of Rogallo (1981) — Numerical experiments in homogeneous turbulence, NASA TM-81315 (no DOI): assemble each quadratic nonlinear term on the grid and on a grid displaced by half a cell, average the two, and truncate spherically at $\kappa_{\max} = \tfrac{\sqrt{2}}{3}N\cdot\tfrac{2\pi}{L} = \tfrac{2\sqrt{2}}{3}\kappa_{\mathrm{Ny}}$ (with $\kappa_{\mathrm{Ny}} = \tfrac{N}{2}\cdot\tfrac{2\pi}{L}$ the Nyquist wavenumber). The half-cell average cancels the aliasing images that wrap in an odd number of axes — the aliasing images being the spurious spectral replicas that the under-resolved quadratic product folds back into the resolved band — while the spherical cutoff removes the surviving two-axis images. It dealiases the quadratic exactly while keeping the resolved band out to $\tfrac{2\sqrt{2}}{3}\kappa_{\mathrm{Ny}} \approx 0.94 \kappa_{\mathrm{Ny}}$ — a factor $\sqrt{2}$ further than the TwoThirds rule's $\tfrac{2}{3}\kappa_{\mathrm{Ny}}$ ($\approx 2.8\times$ the modes in the retained sphere).

Use it when that top third of wavenumbers is worth the price: a second nonlinear-term transform per stage ($2\times$ the transforms) and the displaced-evaluation scratch (a field-scale spectral-representation buffer per phase-shifted term). Because it retains energy out to $\tfrac{2\sqrt{2}}{3}\kappa_{\mathrm{Ny}}$ it takes a proportionally smaller advective-CFL step than the $2/3$ rule — handled automatically by recommended_cfl.

A half-cell shift attenuates the Nyquist mode

A half-cell displacement cannot translate the Nyquist mode of a real field — it attenuates it by $\cos(\pi h_a/\Delta x_a)$, which vanishes at half a cell. This never bites here: the spherical cutoff at $\tfrac{2\sqrt{2}}{3}\kappa_{\mathrm{Ny}} < \kappa_{\mathrm{Ny}}$ leaves the field with no Nyquist content to mistranslate.

The dealiasing cutoff it sets — the dealiasing cutoff — the highest wavenumber the run treats as resolved signal, and the resolution criterion $\kappa_{\max}\eta$ a run is built to meet.

GBGIsotropicTurbulence.SimulationDomain.max_wavenumber — Function
max_wavenumber(domain)

The dealiasing cutoff of domain (a FixedDomain) — the highest wavenumber magnitude the run treats as resolved signal, and for a truncating strategy the highest it evolves at all (under HouLi the modes above it are damped rather than removed) — the dealiasing cutoff

\[\kappa_{\max} = f \frac{N}{2} \frac{2\pi}{L},\]

with $N$ the grid points per side, $L$ the box side, and $f$ the retained-Nyquist fraction of the DealiasingStrategy ($2/3$ for TwoThirds, $1$ for HouLi, $\tfrac{2\sqrt{2}}{3}$ for PhaseShift). It is the cutoff the dealiasing sets — not the grid Nyquist $\tfrac{N}{2}\tfrac{2\pi}{L}$ itself. The modes above it are zeroed each step by the two sharp strategies; HouLi, whose band runs to the Nyquist wavenumber, damps them instead (to machine epsilon at Nyquist). It fixes both the advective-CFL step (recommended_cfl) and the resolution criterion $\kappa_{\max}\eta$ — with $\eta$ the Kolmogorov (dissipation) microscale — that a run is set up to meet.

Band truncation

Restrict a field in spectral representation to the retained band, in place, by the domain's low-pass kernel. Under PhaseShift this is only part of the dealiasing — the averaging of two displaced evaluations is the other half, and the generator performs it where it assembles the product.

GBGIsotropicTurbulence.SimulationDomain.truncate_to_band! — Function
truncate_to_band!(field, domain)

Apply the run's dealias low-pass kernel domain.dealias — domain a FixedDomain — to field in place: a coefficientwise multiply that controls the aliasing of the quadratic nonlinearity. The kernel is whatever the run's DealiasingStrategy built: the sharp $2/3$ cutoff (TwoThirds, exact dealiasing), the smooth HouLi filter (which only damps the aliasing), or the spherical $\tfrac{2\sqrt{2}}{3}\kappa_{\mathrm{Ny}}$ truncation (PhaseShift). The field may be a vector or scalar field in spectral representation. Returns field.

This verb truncates; under PhaseShift that is half the dealiasing

For TwoThirds this call is the whole of it, and for HouLi the taper damps the aliases rather than removing them. Under PhaseShift it is only the second half, so calling it on a product assembled without the displaced-evaluation average leaves that product aliased — the generator pairs the two, and a hand-built assembly must do the same.
