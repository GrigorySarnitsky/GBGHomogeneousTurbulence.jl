"""
    ObservablesCache(domain; scalar = false, particle_velocities = nothing)

The observables cache of a run — the stamped storage where each iteration deposits, at its end, the
observables its own schedule produces: the velocity ``\\boldsymbol{u}`` and vorticity
``\\boldsymbol{\\omega}`` in physical representation, the scalar ``\\varphi`` in physical
representation when the run carries one, the maximum velocity component (the `max_speed` number
the next timestep choice reads), and — when the run advects tracers — the particle velocities
``\\boldsymbol{u}(t_n, \\boldsymbol{X}(t_n))``. The contents are automatic — derived from the
configuration, never declared: the cache holds exactly what the iteration computes, materializes,
and leaves alive at the iteration's end, and nothing may be added on any cost axis.

Build it on a [`FixedDomain`](@ref) `domain`; pass `scalar = true` when the run evolves a passive
scalar (it adds the scalar's slot), and `particle_velocities` — the tracer set's own point-value
storage — when the run advects tracers (the slot IS that storage, stamped here; the tracers' push
writes it). The `Simulation` front door — the build-everything convenience constructor — builds,
wires, and seeds one for you.

Read through the accessors — [`velocity_physical`](@ref), [`vorticity_physical`](@ref),
[`scalar_physical`](@ref), and `max_speed` — each of which returns the deposited value or throws.
Nothing in the cache is ever recomputed: a read that finds a stale, taken, or never-deposited slot
reports a scheduling error — it throws an `ErrorException` whose message names the slot and which
of the three states it is in — and the only repair is to fix the schedule that failed to deposit.

!!! note
    A slot is also its producer's register: between deposits the step works in the same array, so a
    cached field is only valid between iterations. Treat every returned array as
    read-only — it is the storage the next iteration will work in.

"""
    run!(callback, sim)
    run!(sim) do sim … end

Observe and advance `sim` until the observation stops it, and return it. After every iteration —
and once at the seeded initial state, before any advance —
the `callback` **observes** the run as `callback(sim)`: it reads the
state and the cached observables, records what it wants, and returns `true` to continue or `false`
to stop (any other return throws — the decision may not be left implicit). Only then does the next
iteration run: the timestep from the cached maximum speed, the step, the tracer push, and the closing
deposits. The schedule never varies with how the run is driven, so the closing deposit's maximum-speed
reduction and its host readback happen every iteration even under a fixed `dt` that never reads them. A run of ``n`` iterations therefore observes ``n + 1`` instants — the first before any
step, the last after the final one, with statistics recorded before the stop.

Stopping is the observation's decision on observables, never a run option: a budget is a callback
that accumulates what it budgets. A span of simulation time compares [`current_time`](@ref) against
a target; a step budget compares [`current_step`](@ref); an eddy-turnover budget accumulates
``\\Delta t \\varepsilon/k`` from the observables it computes; spin-up to stationarity is the
packaged [`StationarityCriterion`](@ref). Whatever the callback needs beyond the cached observables
it computes itself, at its own cadence, with the exported reductions and recoveries.

# Examples
```julia
run!(sim) do s
    current_time(s) < 5.0                        # a span of simulation time
end

history = Float64[]                              # record k at every observation; stop at 200 steps
run!(sim) do s
    push!(history, kinetic_energy(s.state.velocity))
    current_step(s) < 200
end

run!(StationarityCriterion(), sim)               # spin up to statistical stationarity
```
"""
function run!(callback, sim::Simulation)
  while true
    keep = callback(sim)
    keep isa Bool ||
      throw(ArgumentError("the observation callback must return a Bool — true to continue the " *
                          "run, false to stop it; it returned a $(typeof(keep))"))
    keep || break
    advance!(sim)
  end
  return sim
end
