API overview

The package is an umbrella module (GBGIsotropicTurbulence) assembled from submodules, in dependency order: SimulationState → Dynamics → Observables → Forcing → TimeIntegration → Particles → SimulationRun. The umbrella re-exports their public surface, so using GBGIsotropicTurbulence brings everything into scope.

  • GBGIsotropicTurbulence: the top-level module and public re-export surface.
  • SimulationState: the spectral machinery (SpectralOperators, incl. the pluggable DealiasingStrategy), the preallocated buffers (Workspace), the scratch allocators, and the random initial conditions — a divergence-free velocity and a mean-zero scalar $\varphi$.
  • Dynamics: the flow's equations of motion — the rotational-form Navier–Stokes right-hand side (de-aliased, Leray-projected nonlinear term), the passive-scalar advection, and the exact viscous integrating factor.
  • Observables: the measured functions of state — kinetic energy, dissipation, the velocity-derivative skewness, the scalar variance and dissipation, and the maximum velocity component that sets the CFL step (max_speed).
  • Forcing: the pluggable energy-injection strategies under AbstractForcing (NoForcing, BandRescaling, Linear, ConstantPower, StochasticOU).
  • TimeIntegration: the pluggable integrating-factor time-stepping schemes under AbstractIntegrator (IFRK2, IFLowStorageRK3).
  • Particles: Lagrangian tracer tracking — Tracers, second-order advect! (Heun-in-time), and sample! for the Lagrangian statistics.
  • SimulationRun: the ergonomic run layer — Simulation and the functions that advance it: advance!, run!, and warmup!.

The reference turbulence laws (model spectra, structure-function laws, scaling constants) live in a separate, opt-in Phenomenology group — not re-exported by the umbrella, and designed to be extractable into a standalone package.
