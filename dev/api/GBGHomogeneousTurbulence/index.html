GBGHomogeneousTurbulence

Tools for simulating homogeneous isotropic turbulence on three-dimensional periodic domains: a velocity field and a single passive scalar, each optionally forced, sampled along particle trajectories. It has these submodules:

  • SimulationDomain — the discretized box.

  • State — the evolving fields.

  • Observables — the measured quantities.

  • Cache — the observables cache.

  • Forcing — the energy-injection strategies.

  • Generator — the equations of motion.

  • Propagator — the integrating-factor time-steppers.

  • Particles — the Lagrangian tracers.

  • SimulationRun — the run layer, checkpointing (write_simulation) once HDF5 is loaded.

Statistics over the flow and its samples are the caller's analysis: GBGPeriodicFields supplies the field reductions, GBGStreamingStatistics the online estimators.

The GBG in the name is Göteborg (Gothenburg, Sweden), its birthplace.
