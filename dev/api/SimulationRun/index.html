SimulationRun

GBGIsotropicTurbulence.SimulationRun — Module
SimulationRun

The run layer: Simulation (the assembled state of a case) and the functions that advance it — advance! (one step), run! (advance to a stopping condition, with an optional per-interval callback), and warmup! (spin up to statistical stationarity). The observables kinetic_energy, dissipation, and scalar_variance accept a Simulation directly.

The simulation

The assembled, ready-to-run case — the front-door Simulation(; resolution, viscosity, …) and the operators-taking Simulation(ops; …) constructors. The observables kinetic_energy, dissipation, and scalar_variance also accept a Simulation directly.

GBGIsotropicTurbulence.SimulationRun.Simulation — Type
Simulation

A ready-to-run case: the SpectralOperators machinery, the Workspace scratch, the Physics, the chosen integrator, the velocity $\hat{\boldsymbol u}$ and passive scalar $\hat\varphi$ in spectral representation, any Tracers, and a clock. Build it with the constructors below and advance it with advance! / run! / warmup!.

Driving the run

Advance one step, run to a stopping condition (with an optional per-interval callback), then spin up to statistical stationarity.

GBGIsotropicTurbulence.SimulationRun.advance! — Function
advance!(sim; dt = nothing)

Advance sim by one timestep in place and return it. With dt = nothing the step size is the advective-CFL value for the current velocity; pass dt to force a fixed step. Advects the tracers, if any, by Heun-in-time on the start- and end-of-step velocities, and updates the clock.

GBGIsotropicTurbulence.SimulationRun.run! — Function
run!(sim; turnovers | time | steps, every = nothing)
run!(sim; ...) do sim … end

Advance sim until exactly one stopping condition is met — a number of eddy-turnover times (turnovers, in units of $k/\varepsilon$), a span of simulation time, or a number of steps — and return it. A callback (the do block, or a first positional function) fires with the current Simulation after every step, or once per every units of simulation time if every is given — the hook for streaming statistics along the run.

GBGIsotropicTurbulence.SimulationRun.warmup! — Function
warmup!(sim; gate_scalar = true, gate_skewness = true, min_turnovers = 5, window_turnovers = 4,
        tol = 0.05, skew_floor = 0.1, max_turnovers = 60)
warmup!(sim; turnovers | time | steps)

Spin sim up to a statistically stationary state before measurement, and return it. By default it detects stationarity: it advances until the running dissipation $\varepsilon(t)$ stops drifting — a two-half-window mean test over the trailing window_turnovers eddy-turnover times, relative drift below tol, not tested before min_turnovers (past the start-up overshoot) — and gives up at max_turnovers with a warning. $\varepsilon$ (the small scales, which settle last) is read rather than the kinetic energy, which a constant-energy forcing clamps flat and a fixed-injection forcing makes ring.

Two stricter gates are on by default. With gate_skewness, the velocity-derivative skewness (derivative_skewness) must also have plateaued and reached $\lvert S\rvert \ge$ skew_floor — the decisive "real turbulence yet" signal, since a random-phase field starts at $S \approx 0$ and only a developed cascade reaches $S \approx -0.5$. With gate_scalar, when the scalar is forced, the scalar variance $\langle\varphi^2\rangle$ must be flat too (the scalar reaches stationarity after the velocity); an unforced scalar has no stationary state and is not gated.

Passing an explicit turnovers, time, or steps instead runs a fixed budget (no detection) — the simple spin-up when the transient length is known.
