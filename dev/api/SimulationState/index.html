GBGIsotropicTurbulence.SimulationState — Module
SimulationState

The spectral machinery and preallocated buffers a run advances: SpectralOperators (the read-only grid, transform plans, multipliers, squared-wavenumber field, and de-alias kernel), the scratch allocators, VelocityWorkspace, and the random divergence-free initial condition.

Public API

GBGIsotropicTurbulence.SimulationState.SpectralOperators — Type
SpectralOperators(resolution, box = 2π; dealias_fraction = 2//3,
                  scalar_type = Float64, array_type = Array)

The reusable, read-only spectral machinery for a cubic homogeneous-isotropic-turbulence run on a grid of resolution points per side, in a periodic box of side box: the Grid3D, the real-to-complex transform plans (one for the velocity, a vector field; one for the scalar $\varphi$), the FieldSpectralMultipliers, the squared-wavenumber array $\lvert\mathbf{k}\rvert^{2}$ (with $\mathbf{k}$ the wavenumber vector — the symbol of $-\nabla^{2}$), and the de-alias kernel dealias.

dealias is an isotropic sharp low-pass that keeps the modes $\lvert\mathbf{k}\rvert \le \texttt{dealias\_fraction}\cdot k_{\max}$ ($k_{\max}$ the Nyquist wavenumber) — the $2/3$ rule (dealias_fraction = 2//3) that removes the aliasing error of the quadratic nonlinearity.

array_type selects the storage backend (Array for CPU, ROCArray/CuArray for GPU) and scalar_type the real element type (Float32 is GPU-friendly).

GBGIsotropicTurbulence.SimulationState.Workspace — Type
Workspace(ops)

Preallocated scratch for one coupled integrating-factor step of the velocity and the passive scalar $\varphi$. The velocity buffers are the spectral vorticity, two Runge–Kutta stage registers, the predictor field, a velocity copy (the in-place inverse transform consumes its source), a general spectral scratch, the nonlinear-term buffer, and the physical velocity / vorticity / predictor / Lamb-vector ($\mathbf{u}\times\boldsymbol{\omega}$). The scalar buffers are two stage registers, a predictor, the nonlinear-term buffer, a copy, the shared integrating factor, and the physical scalar; the scalar flux $\mathbf{u}\varphi$ reuses the physical and spectral velocity scratch. Sized so a step allocates no field-sized memory.

GBGIsotropicTurbulence.SimulationState.random_scalar! — Method
random_scalar!(phih, ops; variance = 1.0, peak_wavenumber = 2.0, rng = default_rng())

Fill phih (the scalar $\varphi$ in spectral representation) with a random, mean-zero scalar concentrated at large scales by the envelope $\exp\!\big(-\lvert\mathbf{k}\rvert^{2}/k_p^{2}\big)$ ($k_p$ is peak_wavenumber), de-aliased, and rescaled so the variance $\langle\varphi^{2}\rangle$ equals variance. The physical noise is made mean-zero before the transform, so the $\mathbf{k}=\mathbf 0$ (mean) mode vanishes.

GBGIsotropicTurbulence.SimulationState.random_solenoidal_velocity! — Method
random_solenoidal_velocity!(uh, ops; energy = 0.5, peak_wavenumber = 2.0, rng = default_rng())

Fill uh (a velocity field in spectral representation) with a random, divergence-free velocity $\mathbf{u}$ concentrated at large scales by the envelope $\exp\!\big(-\lvert\mathbf{k}\rvert^{2}/k_p^{2}\big)$ ($k_p$ is peak_wavenumber), de-aliased, and rescaled so the kinetic energy $\tfrac12\langle\lvert\mathbf{u}\rvert^{2}\rangle$ equals energy. The Leray–Helmholtz projection $\mathbb{P}$ enforces $\nabla\cdot\mathbf{u} = 0$.
