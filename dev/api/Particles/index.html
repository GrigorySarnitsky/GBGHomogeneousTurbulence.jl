GBGIsotropicTurbulence.Particles — Module
Particles

Lagrangian tracer tracking: Tracers (positions + a pluggable interpolation scheme), the second-order advect! (Heun-in-time on the start- and end-of-step velocity), and sample! for reading a field along the trajectories.

source

Public API

GBGIsotropicTurbulence.Particles.Tracers — Type
Tracers(ops, count; scheme = CatmullRom, rng = default_rng())
Tracers(positions; scheme = CatmullRom)

A set of Lagrangian tracers. The first form seeds count tracers uniformly at random in the periodic box of ops (on the operators' backend and element type); the second wraps a given (M, 3) position array. scheme is the GBGPeriodicFields interpolation scheme used to evaluate the velocity (and any sampled field) at the tracer positions — CatmullRom (the default), LalescuSpline(n, m), or LagrangeSpline(n).

The struct preallocates the predictor positions and the point-value buffers, so advect! allocates no per-step memory.

GBGIsotropicTurbulence.Particles.advect! — Method
advect!(tracers, velocity_start, velocity_end, ops, dt) -> tracers

Advance the tracer positions by one step of size dt, in place, by Heun-in-time on the physical velocity fields at the start (velocity_start $= \mathbf{u}(t_n)$) and end (velocity_end $= \mathbf{u}(t_{n+1})$) of the step:

\[\mathbf{v}_1 = \mathbf{u}(t_n, \mathbf{X}), \quad \mathbf{X}^{*} = \mathbf{X} + \Delta t\,\mathbf{v}_1, \quad \mathbf{v}_2 = \mathbf{u}(t_{n+1}, \mathbf{X}^{*}), \quad \mathbf{X} \leftarrow \mathbf{X} + \tfrac{\Delta t}{2}(\mathbf{v}_1 + \mathbf{v}_2),\]

with positions wrapped into $[0, L)$. This is second-order accurate in time. The start-of-step velocity $\mathbf{v}_1$ is retained (tracer_velocities) as the trajectory velocity for the Lagrangian statistics.

GBGIsotropicTurbulence.Particles.sample! — Method
sample!(out, field, tracers) -> out

Sample the physical field at the current tracer positions into the point-value buffer out (a VectorPointValues for the velocity, a ScalarPointValues for the scalar $\varphi$), using the tracers' interpolation scheme. Used to gather a field along the trajectories for the Lagrangian statistics.
