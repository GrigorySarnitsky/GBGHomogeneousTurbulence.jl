SimulationState

GBGIsotropicTurbulence.SimulationState — Module
SimulationState

The spectral machinery and preallocated buffers a run advances: SpectralOperators (the read-only grid, transform plans, multipliers, squared-wavenumber field, and the de-alias kernel built by a DealiasingStrategy — TwoThirds or HouLi), the scratch allocators, Workspace, and the random initial conditions (random_solenoidal_velocity! for the divergence-free velocity, random_scalar! for the mean-zero scalar $\varphi$). dealias! applies the de-alias kernel to a spectral field in place.

Spectral operators and workspace

The read-only spectral machinery every buffer is allocated from, and the preallocated per-step scratch a run advances.

GBGIsotropicTurbulence.SimulationState.SpectralOperators — Type
SpectralOperators(resolution, box = 2π; dealiasing = TwoThirds(),
                  scalar_type = Float64, array_type = Array)

The reusable, read-only spectral machinery for a cubic homogeneous-isotropic-turbulence run on a grid of resolution points per side, in a periodic box of side box: the Grid3D, the real-to-complex transform plans (one for the velocity, a vector field; one for the scalar $\varphi$; and one for the rank-2 strain tensor of the derivative-skewness diagnostic), the FieldSpectralMultipliers, the squared-wavenumber array $\lvert\boldsymbol{\kappa}\rvert^{2}$ (with $\boldsymbol{\kappa}$ the wavenumber vector — the symbol of $-\nabla^{2}$; kept both as a real array and as a scalar-field kernel for weighted spectral reductions), and the de-alias kernel dealias.

dealias is built by the dealiasing strategy — TwoThirds (the sharp $2/3$ rule, the default) or HouLi (the smooth Hou–Li filter). Both are applied by dealias! as a coefficientwise multiply to control the aliasing error of the quadratic nonlinearity; the choice also sets the advective-CFL ceiling through recommended_cfl.

array_type selects the storage backend (Array for CPU, ROCArray/CuArray for GPU) and scalar_type the real element type (Float32 is GPU-friendly).

GBGIsotropicTurbulence.SimulationState.Workspace — Type
Workspace(ops)

Preallocated scratch for one coupled integrating-factor step of the velocity and the passive scalar $\varphi$. The velocity buffers are the spectral vorticity, two Runge–Kutta stage registers (buffers holding a stage's state and accumulator), the predictor field, a velocity copy (the in-place inverse transform consumes its source), a general spectral scratch, the nonlinear-term buffer, and the physical velocity / start-of-step vorticity / per-stage vorticity / predictor / Lamb-vector ($\boldsymbol{u}\times\boldsymbol{\omega}$). The scalar buffers are two stage registers, a predictor, the nonlinear-term buffer, a copy, the shared integrating factor, and the physical scalar; the scalar flux $\boldsymbol{u}\varphi$ reuses the physical and spectral velocity scratch. Two real per-mode linear-forcing-rate arrays $A(\boldsymbol{\kappa})$ — one for the velocity, one for $\varphi$ — are folded into the integrating factor. Sized so a step allocates no field-sized memory.

De-aliasing strategies

The aliasing-control strategy passed to SpectralOperators — the supertype, then the sharp 2/3-rule default and the smooth Hou–Li filter.

GBGIsotropicTurbulence.SimulationState.DealiasingStrategy — Type
DealiasingStrategy

How the aliasing of the quadratic nonlinearity is controlled. A SpectralOperators is built with one; it fixes the ops.dealias kernel and, through recommended_cfl, the advective-CFL ceiling. Concrete strategies: TwoThirds (the sharp $2/3$ rule, the default) and HouLi (the smooth Hou–Li filter).

source
GBGIsotropicTurbulence.SimulationState.TwoThirds — Type
TwoThirds()

The sharp isotropic $2/3$-rule truncation: keep the modes $\kappa \le \kappa_{\max} = \tfrac23\kappa_{\mathrm{Ny}}$ and zero the rest, where $\kappa_{\mathrm{Ny}} = \tfrac N2\cdot\tfrac{2\pi}{L}$ is the Nyquist wavenumber and $\kappa_{\max}$ the dealiased maximum — two-thirds of the way out to Nyquist. Exact de-aliasing of the quadratic nonlinearity, and the lean, GPU-friendly default.

source
GBGIsotropicTurbulence.SimulationState.HouLi — Type
HouLi(; order = 36, strength = 36)

The smooth Hou–Li spectral filter, transfer function $\exp\!\big(-\,\texttt{strength}\,(\kappa/\kappa_{\mathrm{Ny}})^{\texttt{order}}\big)$, with $\kappa_{\mathrm{Ny}} = \tfrac N2\cdot\tfrac{2\pi}{L}$ the Nyquist wavenumber. order sets the sharpness of the spectral roll-off (higher is closer to a sharp cutoff); strength sets the damping at the Nyquist mode, which is multiplied by $\mathrm{e}^{-\texttt{strength}}$ (defaults $36, 36$, so that mode falls to $\mathrm{e}^{-36}\approx$ machine epsilon). It keeps more modes than the $2/3$ rule but only damps aliasing rather than removing it exactly — a stabilisation, hence an opt-in, not the default. Applied isotropically in $\kappa$ (the filter TurTLE uses, there per-axis). Because it retains energy out to the Nyquist wavenumber it takes a proportionally smaller CFL step than the $2/3$ rule — handled automatically by recommended_cfl.

The de-aliasing cutoff it sets — the highest wavenumber the operators evolve, and the resolution criterion $\kappa_{\max}\eta$ a run is built to meet.

GBGIsotropicTurbulence.SimulationState.max_wavenumber — Function
max_wavenumber(ops)

The highest wavenumber magnitude the operators ops actually evolve — the de-aliasing cutoff

\[\kappa_{\max} = f\,\frac N2\,\frac{2\pi}{L},\]

with $N$ the resolution, $L$ the box side, and $f$ the retained-Nyquist fraction of the DealiasingStrategy ($2/3$ for TwoThirds, $1$ for HouLi). It is the cutoff the de-aliasing sets — not the grid Nyquist $\tfrac N2\tfrac{2\pi}{L}$ itself; the modes above it are zeroed each step. It fixes both the advective-CFL step (recommended_cfl) and the resolution criterion $\kappa_{\max}\eta$ that a run is set up to meet.

De-alias filtering

Apply the operators' de-alias low-pass kernel to a spectral field in place.

GBGIsotropicTurbulence.SimulationState.dealias! — Function
dealias!(field, ops)

Apply the run's de-alias low-pass ops.dealias to field in place — a coefficientwise multiply that controls the aliasing of the quadratic nonlinearity. The kernel is whatever the run's DealiasingStrategy built: the sharp $2/3$ cutoff (TwoThirds, exact de-aliasing) or the smooth HouLi filter (which only damps the aliasing). field may be a vector or scalar field in spectral representation.

Random initial conditions

Seed a large-scale-peaked, de-aliased, rescaled random solenoidal velocity, or a mean-zero scalar φ.

GBGIsotropicTurbulence.SimulationState.random_solenoidal_velocity! — Function
random_solenoidal_velocity!(û, ops; energy = 0.5, peak_wavenumber = 2.0,
                            spectrum = nothing, rng = default_rng())

Fill û (a velocity field in spectral representation) with a random, divergence-free velocity $\boldsymbol{u}$ of a chosen energy spectrum, de-aliased and rescaled so the kinetic energy $\tfrac12\langle\lvert\boldsymbol{u}\rvert^{2}\rangle$ equals energy. The Leray–Helmholtz projection $\mathbb{P}$ enforces $\nabla\cdot\boldsymbol{u} = 0$.

By default (spectrum = nothing) the velocity is concentrated at large scales by the Gaussian envelope $\exp\!\big(-\lvert\boldsymbol{\kappa}\rvert^{2}/k_p^{2}\big)$ ($k_p$ is peak_wavenumber). Pass spectrum, a function $\kappa \mapsto E(\kappa)$ giving a target radial energy spectrum, to seed that shape instead: each mode is scaled by $\sqrt{E(\kappa)}/\kappa$, so the shell-summed spectrum is $\propto \kappa^{2}(\sqrt{E}/\kappa)^{2} = E(\kappa)$ (the $\kappa^{2}$ is the shell's mode count) and the overall amplitude is fixed by the energy rescaling. The run layer bridges a Phenomenology model spectrum into this function.

ops is the SpectralOperators supplying the grid, backend, wavenumber multipliers, and de-alias kernel; rng is the random stream (defaults to Random.default_rng()).

GBGIsotropicTurbulence.SimulationState.random_scalar! — Function
random_scalar!(φ̂, ops; variance = 1.0, peak_wavenumber = 2.0, rng = default_rng())

Fill φ̂ (the scalar $\varphi$ in spectral representation) with a random, mean-zero scalar concentrated at large scales by the envelope $\exp\!\big(-\lvert\boldsymbol{\kappa}\rvert^{2}/k_p^{2}\big)$ ($k_p$ is peak_wavenumber), de-aliased, and rescaled so the variance $\langle\varphi^{2}\rangle$ equals variance. The physical noise is made mean-zero before the transform, so the $\boldsymbol{\kappa}=\boldsymbol 0$ (mean) mode vanishes.

ops is the SpectralOperators supplying the grid, backend, wavenumber multipliers, and de-alias kernel; rng is the random stream (defaults to Random.default_rng()).
