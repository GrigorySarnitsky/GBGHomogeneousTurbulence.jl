GBGIsotropicTurbulence.Phenomenology.StructureFunctions.Kolmogorov1941 — Type
Kolmogorov1941(; C₂ = 2.0)

The Kolmogorov (1941) inertial-range structure-function laws for the longitudinal velocity increment $\delta u_L$. structure_function(law, r, fp; order) returns:

  • order = 2 — the 2/3 law $D_{LL}(r) = C_2\,(\varepsilon r)^{2/3}$, the second-order increment; the constant C₂ ≈ 2.0 is empirical (default 2.0).
  • order = 3 — the 4/5 law $D_{LLL}(r) = -\tfrac{4}{5}\,\varepsilon r$, the third-order increment; this one is exact (a consequence of the Kármán–Howarth–Monin relation), carrying no free constant.

Both hold in the inertial range $\eta \ll r \ll L$. fp (a FlowParameters) supplies the dissipation rate $\varepsilon$. Any other order throws — K41 fixes only these two longitudinal moments universally.
