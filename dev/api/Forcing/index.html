Forcing

GBGIsotropicTurbulence.Forcing — Module
Forcing

The pluggable energy-injection strategies, as concrete AbstractForcing subtypes dispatched by force!. One implementation serves both the velocity and the scalar $\varphi$, since the strategies are written through tensor-order-generic field operators.

source

Public API

GBGIsotropicTurbulence.Forcing.AbstractForcing — Type
AbstractForcing

Supertype of the energy-injection strategies. A strategy implements force!(forcing, field, ops, scratch), modifying field (a vector or scalar field in spectral representation) in place; scratch is a caller-provided spectral buffer of matching tensor order.

source
GBGIsotropicTurbulence.Forcing.BandRescaling — Type
BandRescaling(ops; energy, lowest_shell = 1, highest_shell = 2)

Deterministic constant-energy forcing. Each step, the in-band Fourier modes ($\texttt{lowest\_shell} \le \lvert\mathbf{k}\rvert \le \texttt{highest\_shell}$, in integer shells of $2\pi/L$ for a box of side $L$) are rescaled by a single factor so the band holds the fixed energy $\tfrac12\langle\lvert\cdot\rvert^{2}\rangle_{\mathrm{band}} = \texttt{energy}$ (for the velocity this is band kinetic energy; for the scalar $\varphi$, band variance).

Rescaling existing modes preserves the divergence-free constraint, so this forcing needs no projection. It is the forcing of the GBGPeriodicFields HIST_CPU demo; note it fixes the band energy, not the injection rate, so the total energy oscillates slowly about its mean.

GBGIsotropicTurbulence.Forcing.NoForcing — Type
NoForcing()

The unforced case: force! is a no-op (a freely decaying field).

source
GBGIsotropicTurbulence.Forcing.force! — Function
force!(forcing, field, ops, scratch)

Apply the energy-injection strategy forcing to field (a velocity or scalar $\varphi$ field in spectral representation) in place, using the spectral scratch buffer (matching field's tensor order) and the operators ops. Dispatches on the concrete forcing type; see NoForcing and BandRescaling.
