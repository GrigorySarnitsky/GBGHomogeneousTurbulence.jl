## The state

The evolving fields a run advances, in spectral representation — the single source of truth. The
physical representations are recovered from it with the source-preserving scratch arity of
[`to_physical!`](@extref GBGPeriodicFields GBGPeriodicFields.Fields.to_physical!), and the vorticity
with [`vorticity_physical!`](@ref) — see [Observables](Observables.md).

```@docs
ResolvedFields
```

## Random initial conditions

Seed a large-scale-peaked, dealiased, rescaled random solenoidal velocity, or a mean-zero scalar.

```@docs

random_scalar!
```

"""
    ResolvedFields(domain; scalar = false)

The record of the evolving fields a run advances, in spectral representation — the single source of
truth, a passive container with every operation external. The velocity, vorticity, and scalar in
physical representation are recoveries of it, not part of it: the iteration recovers them into the stamped slots of the
[`ObservablesCache`](@ref GBGHomogeneousTurbulence.Cache.ObservablesCache) at its end (a slot's stamp
records the instant its value belongs to; never on a
read — a cached read serves the deposited value or throws), so the state itself cannot go stale.
Build it on a [`FixedDomain`](@ref); pass `scalar = true` to carry a passive scalar.

# Fields
- `velocity` — the velocity in spectral representation, ``\\hat{\\boldsymbol{u}}``.
- `scalar` — the scalar in spectral representation, ``\\hat\\varphi``, or `nothing` when the run carries
  no passive scalar.
"""
struct ResolvedFields{UH, PH}
  velocity::UH                   # û (spectral) — the resolved velocity, the single source of truth
  scalar::PH                     # φ̂ (spectral), or nothing when the run carries no scalar
end

ResolvedFields(domain::FixedDomain; scalar::Bool = false) =
  ResolvedFields(new_vector_field_spectral(domain), scalar ? new_scalar_field_spectral(domain) : nothing)
