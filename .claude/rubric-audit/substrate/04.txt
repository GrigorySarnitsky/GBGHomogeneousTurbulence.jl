# GBGHomogeneousTurbulence.jl

A small, focused pseudospectral DNS of homogeneous isotropic turbulence on three-dimensional periodic
domains: an incompressible velocity field and a single passive scalar, each optionally forced,
advanced by a choice of integrating-factor time-stepping scheme, with Lagrangian particle tracking
and Eulerian + Lagrangian statistics.

This package builds on [`GBGPeriodicFields.jl`](https://github.com/GrigorySarnitsky/GBGPeriodicFields.jl),
which supplies the underlying field representations, FFT transforms, fiberwise algebra, differential
operators, reductions, and grid↔point transfer.

The `GBG` part in the name comes from the city of Göteborg (Gothenburg, Sweden), where the primary
development took place.

## Installation

With ``\boldsymbol{u}`` the velocity, ``\boldsymbol{\omega} = \nabla\times\boldsymbol{u}`` the vorticity,
``\nu`` the kinematic viscosity, ``\mathbb{P}`` the Leray–Helmholtz projection onto divergence-free
fields, and ``\boldsymbol{f}`` a forcing, the momentum equation is advanced in rotational form (its
advective term carried by the Lamb vector ``\boldsymbol{u}\times\boldsymbol{\omega}``),

```math
\partial_t \boldsymbol{u} = \mathbb{P} (\boldsymbol{u}\times\boldsymbol{\omega}) + \nu\nabla^{2}\boldsymbol{u} + \boldsymbol{f},
\qquad \nabla\cdot\boldsymbol{u} = 0,
```

and the passive scalar ``\varphi`` by the advection–diffusion equation

```math
\partial_t \varphi = -\nabla\cdot(\boldsymbol{u} \varphi) + \varkappa\nabla^{2}\varphi + f_\varphi,
```

with ``\varkappa = \nu/\mathrm{Sc}`` the scalar diffusivity, ``\mathrm{Sc}`` the Schmidt number, and ``f_\varphi`` a forcing on the scalar. In both
equations the diffusive (stiff) term is integrated exactly through an integrating factor, the
nonlinear term explicitly by a Runge–Kutta stage combination, and the quadratic product is
dealiased by the default ``2/3`` rule (other strategies are available).

## Components

- [`SimulationDomain`](api/SimulationDomain.md): the discretized periodic box a run lives on — the
  `FixedDomain`, its choice of `DealiasingStrategy`, and the scratch-field allocators.
- [`State`](api/State.md): the evolving state (`ResolvedFields`, the single source of truth) a step
  advances, and the random initial conditions — a divergence-free velocity and a mean-zero scalar.
- [`Observables`](api/Observables.md): the measured functions of state — the energy and dissipation
  diagnostics of the flow and the scalar (`kinetic_energy`, `dissipation`, …), the spectrum-derived
  scales (`energy_spectrum`, `integral_scale`), the advective-CFL `max_speed`, and the field-valued
  vorticity recovery.
- [`Cache`](api/Cache.md): the `ObservablesCache` — the stamped storage each **iteration** (one
  advance of the run: a step plus the deposit that closes it) fills at its
  end with the observables of the state it just produced; the checked accessors
  (`velocity_physical`, `max_speed`, …) serve the deposited value or throw, and nothing is
  recomputed on a read.
- [`Forcing`](api/Forcing.md): the interchangeable energy-injection strategies under `AbstractForcing`,
  chosen independently for the velocity and the scalar.
- [`Generator`](api/Generator.md): the flow's equations of motion — the rotational-form Navier–Stokes
  right-hand side, the passive-scalar advection, and the exact viscous integrating factor — reified as
  the `ResolvedGenerator` a scheme consumes through the generator protocol.
- [`Propagator`](api/Propagator.md): the interchangeable integrating-factor schemes under
  `AbstractIntegrator`.
- [`Particles`](api/Particles.md): Lagrangian tracer tracking — second-order advection and field
  sampling along trajectories, with a selectable interpolation scheme.
- [`SimulationRun`](api/SimulationRun.md): the ergonomic run layer — assembles a `Simulation` and
  runs it with `advance!` / `run!` / `warmup!` (the CFL-adaptive loop with automatic warm-up to
  stationarity); it reports the measured flow state (`flow_parameters`) and compares the measured

function advect!(tracers::Tracers, velocity_end, domain::FixedDomain, dt::Real)
  L = real(eltype(tracers.positions))(domain.grid.domain_size[1])
  Δt = real(eltype(tracers.positions))(dt)
  X = tracers.positions
  Xstar = tracers.predictor

  v1 = point_values(tracers.trajectory_velocity)
  Xstar .= mod.(X .+ Δt .* v1, L)
  # v₂ is evaluated at the PREDICTOR positions and is a stage register, never deposited particle velocities —
  # and it must never be reused as the next step's v₁: the two differ only at O(Δt²), but that reuse
  # would corrupt the recorded observable the Lagrangian statistics accumulate (never approximate
  # the thing you measure).
  interpolate!(tracers.predictor_velocity, velocity_end, tracers.predictor_points, tracers.scheme)
  v2 = point_values(tracers.predictor_velocity)
  X .= mod.(X .+ (Δt / 2) .* (v1 .+ v2), L)
  return tracers
end


"""
    sample!(out, field, tracers) -> out

Sample the physical `field` at the current tracer positions into the point-value buffer `out` (a
[`VectorPointValues`](@extref GBGPeriodicFields GBGPeriodicFields.Points.VectorPointValues) for the
velocity, a [`ScalarPointValues`](@extref GBGPeriodicFields GBGPeriodicFields.Points.ScalarPointValues)
for the scalar ``\\varphi``), using the interpolation scheme of the tracer set `tracers`. Used to gather a field along the trajectories for the forthcoming Lagrangian
statistics.
"""
function sample!(out, field, tracers::Tracers)
  interpolate!(out, field, tracers.position_points, tracers.scheme)
  return out
end


"""
    particle_positions(tracers)
    particle_positions(sim)

The `(M, 3)` array of current tracer positions — the probes' own state, read off the tracer set
`tracers`. The second form reads a `Simulation`'s tracers (and throws an `ArgumentError` when the
run advects none).
"""
particle_positions(tracers::Tracers) = tracers.positions


"""
    number_of_tracers(tracers)

The number of tracers ``M`` in the tracer set `tracers`.
"""
number_of_tracers(tracers::Tracers) = size(tracers.positions, 1)
