GBGHomogeneousTurbulence.GBGHomogeneousTurbulence — Module
GBGHomogeneousTurbulence

Tools for simulating homogeneous isotropic turbulence on three-dimensional periodic domains: a velocity field and a single passive scalar, each optionally forced, advanced by a choice of integrating-factor time-stepping scheme, with Lagrangian particle tracking and field sampling.

The package produces the flow and the values sampled from it; accumulating statistics over them is the caller's own analysis, for which the two sibling packages supply the tools — GBGPeriodicFields the field reductions and GBGStreamingStatistics the online estimators.

A run checkpoints to HDF5 and restores from it — write_simulation / read_simulation, once the HDF5 package is loaded.

Built on GBGPeriodicFields.

The GBG part in the name comes from the city of Göteborg (Gothenburg, Sweden), where the primary development took place.

source

The umbrella module sets the include order and re-exports the public surface of the submodules.
