Spectra

GBGIsotropicTurbulence.Phenomenology.Spectra — Module
Phenomenology.Spectra

Model spectra — parametrizations of the reference velocity spectrum $E(\kappa)$ and the scalar spectrum $E_\varphi(\kappa)$, evaluated by spectrum. A velocity model is composed — an inertial-range core times a large-scale roll-off and a dissipation-range roll-off, each swappable — and ModelSpectrum owns the formula.

  • ModelSpectrum — the composed velocity spectrum: a Kolmogorov constant, a LargeScaleFactor, and a DissipationFactor.
  • LargeScaleFactor / DissipationFactor — the swappable roll-off pieces, evaluated by large_scale_factor / dissipation_factor: PopeLargeScale / PopeDissipation are Pope's forms, VonKarmanLarge the classic $\kappa^{4}$ energy range, PaoDissipation Pao's cutoff, ExponentialDissipation the closure-predicted exponential cutoff, SaffmanDissipation a Gaussian cutoff, and UnitLargeScale / UnitDissipation are the trivial (no-roll-off) factors.
  • EnergySpectrum — the velocity-spectrum family root; Pope2000 / VonKarman1948 / Pao1965 are its named presets, each a composed ModelSpectrum.
  • ScalarSpectrum — the passive-scalar spectra; ObukhovCorrsin1949 is the inertial-convective range.

Every preset is a type with a keyword constructor, invoked as Name(; …). The velocity-spectrum presets Pope2000 / VonKarman1948 / Pao1965 name the ModelSpectrum specialization carrying their large-scale and dissipation factors, so a preset is the composition rather than a wrapper around one; the scalar preset ObukhovCorrsin1949, like the structure-function and scaling laws, is a plain struct.

GBGIsotropicTurbulence.Phenomenology.Spectra.ModelSpectrum — Type
ModelSpectrum(C_K, large_scale, dissipation, ref)

The composed model energy spectrum

\[E(\kappa) = C_K \varepsilon^{2/3} \kappa^{-5/3} f_L(\kappa L) f_\eta(\kappa\eta),\]

an inertial-range core with Kolmogorov constant C_K times a large-scale roll-off large_scale (a LargeScaleFactor, giving $f_L$) and a dissipation-range roll-off dissipation (a DissipationFactor, giving $f_\eta$); ref is its Reference. Build one directly to mix roll-off forms, or use a preset such as Pope2000. Evaluated by spectrum(model, κ, fp), which reads $\varepsilon$ and the roll-off's own length $L$ (see large_scale_length — $L_{11}$ for most forms, $k^{3/2}/\varepsilon$ for Pope's) from fp and forms $\eta$ with kolmogorov_length.

This is the standard generic form for a model spectrum (Sagaut & Cambon 2018; Pope 2000); the large-scale roll-off sets the low-wavenumber slope $E(\kappa\to 0)\propto\kappa^\sigma$ — $\sigma = 2$ (the Saffman-type $\kappa^{2}$ low-wavenumber spectrum, the PopeLargeScale default) or $\sigma = 4$ (the Batchelor-type $\kappa^{4}$, VonKarmanLarge).

Fields

The plain constructor ModelSpectrum(C_K, large_scale, dissipation, ref) takes the four fields directly, in this order:

  • C_K — the Kolmogorov constant of the inertial-range core.
  • large_scale — the LargeScaleFactor giving $f_L$.
  • dissipation — the DissipationFactor giving $f_\eta$.
  • ref — the Reference reported as the model's provenance.

Roll-off factors

The swappable large-scale and dissipation-range shapes, and Pope's forms.

GBGIsotropicTurbulence.Phenomenology.Spectra.LargeScaleFactor — Type
LargeScaleFactor

Supertype of the dimensionless large-scale roll-off factors $f_L(\kappa L)$ of a composed ModelSpectrum — the shape that bends the inertial $\kappa^{-5/3}$ law over into the energy-containing range, with $f_L \to 1$ as $\kappa L \to \infty$. Evaluated by large_scale_factor; PopeLargeScale is Pope's form.

source
GBGIsotropicTurbulence.Phenomenology.Spectra.DissipationFactor — Type
DissipationFactor

Supertype of the dimensionless dissipation-range roll-off factors $f_\eta(\kappa\eta)$ of a composed ModelSpectrum — the shape that cuts the spectrum off near the Kolmogorov scale, with $f_\eta \to 1$ as $\kappa\eta \to 0$. Evaluated by dissipation_factor; PopeDissipation is Pope's form.

Bottleneck models are deliberately deferred

These factors are inertial-normalized cutoffs; bottleneck models are deliberately deferred. Models of the near-dissipation bottleneck — a bump before the cutoff (Qian 1984, doi:10.1063/1.864902; Ishihara et al. 2005, doi:10.1143/JPSJ.74.1464; Kraichnan 1959, doi:10.1017/S0022112059000362 — all of the form $A(\kappa\eta)^\gamma\exp(-\beta\kappa\eta)$ with $\gamma < 0$) — do not satisfy $f_\eta\to 1$ and need a richer spectrum structure; they are deliberately deferred.

source
GBGIsotropicTurbulence.Phenomenology.Spectra.PopeLargeScale — Type
PopeLargeScale(c_L, p₀)

Pope's large-scale roll-off $f_L(\kappa L) = \Bigl(\frac{\kappa L}{\sqrt{(\kappa L)^2 + c_L}}\Bigr)^{5/3 + p_0}$, which tends to 1 in the inertial range and rolls the spectrum off below the integral scale. The coefficient c_L is set by the requirement that the spectrum integrate to the kinetic energy; p₀ fixes the low-wavenumber slope (Pope 2000).

Fields

The plain constructor PopeLargeScale(c_L, p₀) takes the two fields directly:

  • c_L — the large-scale coefficient, set by the energy normalization.
  • p₀ — the low-wavenumber slope exponent.
source
GBGIsotropicTurbulence.Phenomenology.Spectra.PopeDissipation — Type
PopeDissipation(c_η, β)

Pope's dissipation-range roll-off $f_\eta(\kappa\eta) = \exp\!\bigl(-\beta\{[(\kappa\eta)^4 + c_\eta^4]^{1/4} - c_\eta\}\bigr)$, which tends to 1 in the inertial range and cuts the spectrum off near the Kolmogorov scale. c_η is set by the requirement that the spectrum yield the dissipation rate; β fixes the sharpness of the cutoff (Pope 2000).

Fields

The plain constructor PopeDissipation(c_η, β) takes the two fields directly:

  • c_η — the dissipation-range coefficient, set by the dissipation normalization.
  • β — the cutoff-sharpness exponent.
source
GBGIsotropicTurbulence.Phenomenology.Spectra.VonKarmanLarge — Type
VonKarmanLarge(c_L)

The von Kármán large-scale roll-off $f_L(\kappa L) = \Bigl(\frac{(\kappa L)^2}{(\kappa L)^2 + c_L}\Bigr)^{17/6}$, which tends to 1 in the inertial range and produces the classic $\kappa^{4}$ energy-containing range at low wavenumber ($E \sim \kappa^{-5/3}f_L \sim \kappa^{4}$); c_L fixes the peak scale (von Kármán 1948).

Fields

The plain constructor VonKarmanLarge(c_L) takes the field directly:

  • c_L — the coefficient fixing the peak scale.
source
GBGIsotropicTurbulence.Phenomenology.Spectra.UnitLargeScale — Type
UnitLargeScale()

The trivial large-scale factor $f_L \equiv 1$ — no energy-containing roll-off, for a spectrum defined only over the inertial and dissipation ranges (the Pao1965 form).

GBGIsotropicTurbulence.Phenomenology.Spectra.UnitDissipation — Type
UnitDissipation()

The trivial dissipation-range factor $f_\eta \equiv 1$ — no viscous cutoff, for a spectrum defined only over the energy-containing and inertial ranges (the classic VonKarman1948 form).

GBGIsotropicTurbulence.Phenomenology.Spectra.PaoDissipation — Type
PaoDissipation(α)

Pao's dissipation-range roll-off $f_\eta(\kappa\eta) = \exp\!\bigl(-\tfrac{3}{2} \alpha (\kappa\eta)^{4/3}\bigr)$, from the hypothesis that the spectral energy flux stays constant through the dissipation range; α is the Kolmogorov constant $C_K$ (Pao 1965).

Fields

The plain constructor PaoDissipation(α) takes the field directly:

  • α — the Kolmogorov constant the flux hypothesis reuses.
source
GBGIsotropicTurbulence.Phenomenology.Spectra.ExponentialDissipation — Type
ExponentialDissipation(β)

The pure-exponential dissipation-range roll-off $f_\eta(\kappa\eta) = \exp(-\beta \kappa\eta)$ — the $n = 1$ case of the general $\exp(-\beta(\kappa\eta)^n)$ family, and the form the triadic spectral closures — eddy-damped quasi-normal Markovian, direct-interaction approximation, Lagrangian renormalized approximation — consistently predict (Kaneda 1993; Sagaut & Cambon 2018). It is the far-dissipation form ($\kappa\eta \gg 1$), where DNS resolving that range fit $\beta \approx 6.7$ (Khurshid, Donzis & Sreenivasan 2018, doi:10.1103/PhysRevFluids.3.082601; consistent with Chen et al. 1993, doi:10.1103/PhysRevLett.70.3051, $\beta \approx 7.1$); the factor tends to 1 in the inertial range ($\kappa\eta \to 0$). PopeDissipation is asymptotically $\exp(-\beta\kappa\eta)$ too, and carries $\beta = 5.2$ — a lower rate, because Pope fits his $\beta$ across the whole dissipation range including the near-dissipation bend, while the values here are fitted to the far range alone. The two are the same symbol for the same decay, calibrated on different intervals. The near-dissipation range is instead a stretched exponential (exponent $\approx 2/3$; Ishihara et al. 2005), a different form this factor does not model.

Fields

The plain constructor ExponentialDissipation(β) takes the field directly:

  • β — the exponential decay rate.
source
GBGIsotropicTurbulence.Phenomenology.Spectra.SaffmanDissipation — Type
SaffmanDissipation()

A Gaussian dissipation-range roll-off $f_\eta(\kappa\eta) = \exp(-2(\kappa\eta)^2)$ — a simple, parameter-free cutoff that tends to 1 in the inertial range. The Gaussian form follows Saffman (1963, appendix, doi:10.1017/S0022112063000987; roughly half the cutoff coefficient of the earlier Townsend 1951 form, doi:10.1098/rspa.1951.0179), whose coefficient varies with the derivative skewness $S$ — about $2.6$ to $3.3$ across the range of $S$ that paper considers — and is simplified downward to $2$ here for a parameter-free, deliberately soft cutoff, which retains more near-cutoff energy than a measured spectrum shows.

The factor evaluators, extended by each roll-off form, and the length a large-scale form is evaluated against.

GBGIsotropicTurbulence.Phenomenology.Spectra.large_scale_factor — Function
large_scale_factor(f, κL) -> Float64

Evaluate the dimensionless large-scale roll-off f (a LargeScaleFactor) at the argument $\kappa L$ (κL), where $L$ is the length that form's own coefficient was fitted against — large_scale_length supplies it. A new large-scale form is a subtype of LargeScaleFactor that adds a method here, and a method there when its length is not $L_{11}$.

source
GBGIsotropicTurbulence.Phenomenology.Spectra.large_scale_length — Function
large_scale_length(f, fp) -> Float64

The length scale the large-scale roll-off f is evaluated against, read from the flow state fp (a FlowParameters).

This exists because a fitted coefficient belongs to a particular length, and the two published forms here do not use the same one. The default is the longitudinal integral scale $L_{11}$, which VonKarmanLarge uses. PopeLargeScale overrides it with $L_{0} = k^{3/2}/\varepsilon$: Pope's $c_L = 6.78$ is the value that makes $\int_0^\infty E(\kappa)\,\mathrm d\kappa = k$ hold with that length, and feeding the same coefficient $L_{11}$ instead breaks that normalization. The two lengths are related by $L_{11}/L_{0} = C_\varepsilon (2/3)^{3/2}$, so the gap is set by the normalized dissipation constant, not fixed: at $C_\varepsilon = 0.5$ the length is 3.7 times smaller and the spectrum integrates to $0.42k$, and at Pope's high-Reynolds-number $L_{11} = 0.43 L_{0}$ it is 2.3 times smaller and integrates to $0.57k$ ($\int E\,\mathrm d\kappa \propto L^{2/3}$).

Velocity models

The named velocity-spectrum presets of the composed ModelSpectrum.

GBGIsotropicTurbulence.Phenomenology.Spectra.Pope2000 — Type
Pope2000(; C_K = 1.5, c_L = 6.78, p₀ = 2.0, c_η = 0.40, β = 5.2)

The Pope (2000) model spectrum — the ModelSpectrum composition (whose docstring carries the formula) with PopeLargeScale supplying $f_L$ and PopeDissipation supplying $f_\eta$.

C_K is the Kolmogorov constant; the defaults c_L = 6.78, c_η = 0.40 are the high-Reynolds-number values Pope obtains from the energy and dissipation normalizations, with the shape exponents p₀ = 2 and β = 5.2. Override any coefficient to re-fit. Evaluate with spectrum(Pope2000(), κ, fp).

Pope2000 is the ModelSpectrum carrying Pope's two roll-off factors, so spec isa Pope2000 holds for a value this constructor returns, exactly as for the presets that are plain structs.

source
GBGIsotropicTurbulence.Phenomenology.Spectra.VonKarman1948 — Type
VonKarman1948(; C_K = 1.5, c_L = 1.0)

The von Kármán (1948) energy spectrum — a preset ModelSpectrum with the VonKarmanLarge roll-off and no viscous cutoff (UnitDissipation):

ModelSpectrum's docstring carries the composed formula; here $f_L$ is von Kármán's $\bigl((\kappa L)^{2}/((\kappa L)^{2} + c_L)\bigr)^{17/6}$ and $f_\eta$ is unity. It is the classic interpolation between the $\kappa^{4}$ energy-containing range and the $\kappa^{-5/3}$ inertial range, with no dissipation-range cutoff (use Pope2000 when the cutoff matters). C_K is the Kolmogorov constant; c_L fixes where the spectrum peaks and is a shape parameter of this form rather than a normalization — unlike PopeLargeScale's c_L, no energy condition determines it, and the default 1.0 is the conventional choice.

VonKarman1948 is the ModelSpectrum carrying von Kármán's large-scale factor and no dissipation roll-off, so spec isa VonKarman1948 holds for a value this constructor returns.

source
GBGIsotropicTurbulence.Phenomenology.Spectra.Pao1965 — Type
Pao1965(; C_K = 1.5)

The Pao (1965) energy spectrum — a preset ModelSpectrum with no energy-containing roll-off (UnitLargeScale) and the PaoDissipation cutoff:

ModelSpectrum's docstring carries the composed formula; here $f_L$ is unity and $f_\eta$ is Pao's $\exp\!\bigl(-\tfrac{3}{2} C_K (\kappa\eta)^{4/3}\bigr)$. It covers the inertial and dissipation ranges from a constant-spectral-flux hypothesis — the Kolmogorov constant C_K appears in both the amplitude and the cutoff, so the cutoff carries no free constant (unlike Pope2000). It has no energy-containing range; use Pope2000 or VonKarman1948 when the large scales matter.

Pao1965 is the ModelSpectrum carrying Pao's dissipation factor and no large-scale roll-off, so spec isa Pao1965 holds for a value this constructor returns.

source
GBGIsotropicTurbulence.Phenomenology.Spectra.ObukhovCorrsin1949 — Type
ObukhovCorrsin1949(; C_OC = 0.67)

The Obukhov–Corrsin inertial-convective scalar spectrum

\[E_\varphi(\kappa) = C_{\mathrm{OC}} \varepsilon_\varphi \varepsilon^{-1/3} \kappa^{-5/3},\]

the Obukhov–Corrsin scalar analogue of the Kolmogorov $-5/3$ law: for a Schmidt number of order one the scalar's inertial-convective range coincides with the velocity inertial range. C_OC is the Obukhov–Corrsin constant ($\approx 0.67$ for the three-dimensional spectrum — the high-Reynolds-number value of Sreenivasan 1996, Phys. Fluids 8, 189), quoted — unlike Yaglom's classical $4/3$ — for the full-variance scalar dissipation $2\varkappa\langle\lvert\nabla\varphi\rvert^2\rangle$, so it pairs directly with this package's full-variance $\varepsilon_\varphi$ (scalar_dissipation) with no factor-of-two conversion. The name is a dual eponym — Obukhov (1949) and Corrsin (independently, 1951); the 1949 handle is Obukhov's year. Evaluating spectrum reads the scalar dissipation $\varepsilon_\varphi$ (fp.scalar_dissipation, which must be set) and the kinetic-energy dissipation $\varepsilon$ from fp.

Fields

The plain constructor ObukhovCorrsin1949(C_OC) takes the field directly:

  • C_OC — the Obukhov–Corrsin constant.
