SimulationRun

GBGIsotropicTurbulence.SimulationRun — Module
SimulationRun

The run layer: Simulation (the assembled state of a case) and the functions that advance it — advance! (one step), run! (advance to a stopping condition, with an optional per-interval callback), and warmup! (spin up to statistical stationarity). current_time and current_step report the elapsed time and step count. flow_parameters reports the run's dimensionless flow state (a Phenomenology FlowParameters), and validate_spectrum compares its measured energy spectrum against a Phenomenology model.

source

The simulation

The assembled, ready-to-run case — the front-door Simulation(; grid_points_per_axis, viscosity, …) and the domain-taking Simulation(domain; …) constructors. The observables kinetic_energy, dissipation, scalar_variance, energy_spectrum, and integral_scale also accept a Simulation directly.

GBGIsotropicTurbulence.SimulationRun.Simulation — Type
Simulation(; grid_points_per_axis, k_max_η = 2, kinetic_energy = 1.5,
             side_length = 2π, element_type = Float64, array_type = Array,
             dealiasing = TwoThirds(), kwargs...)
Simulation(domain; k_max_η = 2, kinetic_energy = 1.5, kwargs...)

A ready-to-run case — the FixedDomain, the IntegratorBuffers, the FlowConditions, the chosen integrator, the ResolvedFields state (the velocity $\hat{\boldsymbol u}$ and passive scalar $\hat\varphi$ in spectral representation), any Tracers, and a clock. The first form is the front door: from grid_points_per_axis and side_length it builds every piece with sensible defaults, seeds a divergence-free velocity (and, with scalar = true, a mean-zero scalar $\varphi$), and returns a Simulation at $t = 0$; the second takes a FixedDomain you built yourself. Advance it with advance! / run! / warmup!; read its measured state with the observables (kinetic_energy, dissipation, …) and flow_parameters, and its progress with current_time / current_step.

Setting the Reynolds number

By default the run is forced and stationary — a BandRescaling holds the total (whole-field) energy at kinetic_energy (i.e. over = :total) — and the viscosity is chosen from the grid rather than supplied:

  • Grid mode (no viscosity): the constructor picks the highest Reynolds number consistent with the chosen resolution criterion k_max_η. It reads the dissipation the box sustains from the box-normalized dissipation law Li2008 (in Phenomenology.Scalings), $\varepsilon = (k/G)^{3/2}/L$ with kinetic_energy the kinetic energy $k$, side_length the side $L$, and $G$ the box-normalization group constant ($\approx 0.9$), then sets $\nu$ so that $\kappa_{\max}\eta$ equals k_max_η — the resolution criterion, with $\kappa_{\max}$ the max_wavenumber (the dealiasing cutoff, not the grid Nyquist). Since $\kappa_{\max}\eta = f\pi\,\eta/\Delta x$ with $f$ the retained-Nyquist fraction, k_max_η = 2 gives $\Delta x \approx \eta$ for the default $2/3$ rule ($f = 2/3$); a wider-band strategy resolves a finer $\Delta x$ at the same k_max_η. The kinetic_energy and side_length fix the units; the grid and k_max_η fix $\mathrm{Re}_\lambda \sim N^{2/3}$. The chosen $\nu$, $\varepsilon$, and $\mathrm{Re}_\lambda$ are logged.
  • Explicit mode: pass viscosity and it is used directly (k_max_η is ignored) — for a decaying run (velocity_forcing = NoForcing()) or manual control.

Keywords

The keywords marked (front door only) configure the FixedDomain and are consumed by the first form; the rest are forwarded to the Simulation(domain; …) form.

  • grid_points_per_axis — the number of grid points $N$ along each side (front door only); required.
  • domain — a pre-built FixedDomain, the positional argument of the second form (the front door builds one from grid_points_per_axis, side_length, dealiasing, element_type, array_type).
  • k_max_η = 2 — the resolution criterion $\kappa_{\max}\eta$ used to set $\nu$ in grid mode (the keyword spells $\kappa_{\max}$ in ASCII); $\ge 1.5$ is well-resolved, higher trades Reynolds number for margin.
  • viscosity — the kinematic viscosity $\nu$ (sets $\mathrm{Re} = 1/\nu$); omit for grid mode.
  • kinetic_energy = 1.5 — the initial, and when forced the held, kinetic energy $k$; 1.5 gives $u' = 1$.
  • side_length = 2π — the box side $L$ (front door only).
  • element_type = Float64, array_type = Array — the real element type and storage backend (front door).
  • dealiasing = TwoThirds() — the DealiasingStrategy ($2/3$ sharp, HouLi smooth, or PhaseShift); it sets $\kappa_{\max}$ and hence the CFL step (front door only).
  • schmidt = 1.0 — the Schmidt number $\mathrm{Sc}$ (scalar diffusivity $\nu/\mathrm{Sc}$).
  • velocity_forcing, scalar_forcing — an AbstractForcing (or a DeferredForcing from an operator-free constructor); velocity_forcing defaults to a BandRescaling holding the total (whole-field) energy at kinetic_energy (over = :total), scalar_forcing to NoForcing(). The velocity and scalar are forced independently.
  • scalar = false, scalar_variance = 1.0, peak_wavenumber = 2.0 — whether to evolve a passive scalar (a mean-zero $\varphi$), its initial variance, and the large-scale spectral peak of the initial condition.
  • initial_spectrum = nothing — a Phenomenology EnergySpectrum (e.g. VonKarman1948()) to draw the initial velocity from, in place of the default large-scale Gaussian; its shape is evaluated at the run's state (its integral scale set to 1/peak_wavenumber) and normalized to kinetic_energy.
  • integrator = IFLowStorageRK3(), cfl = recommended_cfl(integrator, domain) — the AbstractIntegrator scheme and its advective-CFL ceiling (adapts to dealiasing).
  • ntracers = 0, tracer_scheme = CatmullRom — the number of Lagrangian Tracers and their interpolation scheme.
  • rng — the random stream for the initial condition and the tracer seeding.

Fields

  • domain, buffers, conditions, integrator — the FixedDomain, IntegratorBuffers, FlowConditions, and the chosen scheme.
  • state — the ResolvedFields (the evolving û, φ̂).
  • tracers, tracer_velocity — the Tracers (or nothing), and the buffer holding the velocity in physical representation for the Heun tracer push.
  • cfl, clock — the advective-CFL coefficient, and the time/step counter.

Advancing the run

Advance one step, run to a stopping condition (with an optional per-interval callback), then spin up to statistical stationarity.

GBGIsotropicTurbulence.SimulationRun.advance! — Function
advance!(sim; dt = nothing)

Advance sim by one timestep in place and return it. With dt = nothing the step size is the advective-CFL value for the current velocity; pass dt to force a fixed step. Advects the tracers, if any, by Heun-in-time on the start- and end-of-step velocities, and updates the clock.

source
GBGIsotropicTurbulence.SimulationRun.run! — Function
run!(sim; turnovers | time | steps, every = nothing)
run!(sim; ...) do sim … end

Advance sim until exactly one stopping condition is met — a number of eddy-turnover times (turnovers, in units of $k/\varepsilon$), a span of simulation time, or a number of steps — and return it. A callback (the do block, or a first positional function) fires with the current Simulation after every step, or once per every units of simulation time if every is given — the place to stream statistics along the run.

Examples

run!(sim; turnovers = 10)                        # advance ten eddy-turnover times

history = Float64[]                              # sample the kinetic energy every 0.1 time units
run!(sim; time = 5.0, every = 0.1) do s
    push!(history, kinetic_energy(s.state.velocity))
end

GBGIsotropicTurbulence.SimulationRun.warmup! — Function
warmup!(sim; gate_scalar = true, gate_skewness = true, min_turnovers = 5,
        window_turnovers = 4, tol = 0.05, skew_floor = 0.1, max_turnovers = 60)
warmup!(sim; turnovers | time | steps)

Spin sim up to a statistically stationary state before measurement, and return it. By default it detects stationarity: it advances until the running dissipation $\varepsilon(t)$ stops drifting — a two-half-window mean test over the trailing window_turnovers eddy-turnover times, relative drift below tol, not tested before min_turnovers (past the start-up overshoot) — and gives up at max_turnovers with a warning. $\varepsilon$ (the small scales, which settle last) is read rather than the kinetic energy, which a constant-energy forcing clamps flat and a fixed-injection forcing makes ring.

Two stricter gates are on by default. With gate_skewness, the velocity-derivative skewness (derivative_skewness) must also have plateaued and reached $\lvert S\rvert \ge \texttt{skew\_floor}$ — the decisive "real turbulence yet" signal, since a random-phase field starts at $S \approx 0$ and only a developed cascade reaches $S \approx -0.5$. With gate_scalar, when the scalar is forced, the scalar variance $\langle\varphi^2\rangle$ must be flat too (the scalar reaches stationarity after the velocity); an unforced scalar has no stationary state and is not gated.

Passing an explicit turnovers, time, or steps instead runs a fixed budget (no detection) — the simple spin-up when the transient length is known.

Flow parameters and spectrum validation

Bridge the run's measured state to a Phenomenology FlowParameters, and compare the measured energy spectrum against a model spectrum.

GBGIsotropicTurbulence.SimulationRun.flow_parameters — Function
flow_parameters(sim)

The dimensionless flow state of sim as a FlowParameters — the bridge that lets any Phenomenology reference law be evaluated at the run's measured state. The viscosity $\nu$ and the Schmidt number are read from sim.conditions; the dissipation $\varepsilon$, the r.m.s. velocity $u' = \sqrt{2k/3}$ (from the kinetic energy $k$), and the longitudinal integral scale $L_{11}$ are measured from the current velocity field. The scalar dissipation is not populated — it is left NaN; the scalar reference laws (Yaglom1949, ObukhovCorrsin1949) that read it take a FlowParameters with scalar_dissipation supplied explicitly.

GBGIsotropicTurbulence.SimulationRun.validate_spectrum — Function
validate_spectrum(sim, model)

Compare the measured energy spectrum of sim against a Phenomenology model spectrum model (an EnergySpectrum, e.g. Pope2000()), evaluated at the run's flow_parameters. The measured energy_spectrum is a per-shell energy ($k = \sum_\kappa E(\kappa)$) while the model is a spectral density ($k = \int_0^\infty E(\kappa)\,\mathrm d\kappa$), so the density is multiplied by the shell width $\Delta\kappa = 2\pi/L$ before comparison — making the two agree at any box side $L$ (not only the default $L = 2\pi$, where $\Delta\kappa = 1$). Returns a named tuple (; wavenumbers, measured, predicted, relative_error): the resolved shell wavenumbers, the measured and predicted per-shell $E(\kappa)$, and the relative L² discrepancy over the resolved (non-empty) shells.

Note

A developed, well-resolved run agrees with a good model across the inertial range; at low Reynolds number or coarse resolution the inertial range is narrow, so a large discrepancy is expected and reflects the run, not the model.
