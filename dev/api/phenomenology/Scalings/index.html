Phenomenology.Scalings

Dimensionless turbulence constants and their Reynolds-number trends, evaluated by scaling.

  • ScalingLaw — the family root every law below subtypes.
  • Sreenivasan1998 — the normalized dissipation constant $C_\varepsilon$ ($L_{11}$ the longitudinal integral scale), a high-Reynolds-number plateau with an optional finite-Reynolds-number correction.
  • Sreenivasan1995 — the (three-dimensional) Kolmogorov constant $C_K$ of the inertial-range spectrum.
  • stationary_dissipation — the dissipation a stationary run sustains, predicted from its energy and box side.
  • Li2008 — the box-normalized dissipation group $G$, the constant stationary_dissipation inverts.

Laws

The dimensionless scaling constants and their Reynolds-number trends, evaluated by scaling.

GBGIsotropicTurbulence.Phenomenology.Scalings.ScalingLaw — Type
ScalingLaw <: TurbulenceLaw

Supertype of the laws for a dimensionless turbulence constant — a pure number characterizing developed turbulence — here the normalized dissipation $C_\varepsilon$, the Kolmogorov constant $C_K$, and the box-normalized dissipation group $G$; each may carry a Reynolds-number dependence. A law predicts the constant via scaling(law, fp); the measured value comes from a run, and the comparison is prediction against measurement.

source
GBGIsotropicTurbulence.Phenomenology.Scalings.Sreenivasan1998 — Type
Sreenivasan1998(; asymptote = 0.5, correction = 0.0)

The normalized dissipation constant $C_\varepsilon = \varepsilon L_{11}/u'^3$ — normalized on the longitudinal integral scale $L_{11}$, not the box side — as a high-Reynolds-number plateau with an optional finite-Reynolds-number correction,

\[C_\varepsilon(\mathrm{Re}_\lambda) = C_{\varepsilon\infty}\Bigl(1 + \frac{a}{\mathrm{Re}_\lambda}\Bigr),\]

with asymptote the plateau $C_{\varepsilon\infty}$ and correction the coefficient $a$ of the $1/\mathrm{Re}_\lambda$ correction. Sreenivasan (1998) established that $C_\varepsilon$ approaches a constant of order $0.5$ (the default; the precise value depends on the integral-scale definition) above $\mathrm{Re}_\lambda \sim 50$. The correction defaults to 0 (the pure plateau); set it to a positive value to model the low-Reynolds-number rise. Evaluating scaling(law, fp) reads $\mathrm{Re}_\lambda$ from fp via taylor_reynolds.

Fields

The plain constructor Sreenivasan1998(asymptote, correction) takes the two fields directly:

  • asymptote — the plateau $C_{\varepsilon\infty}$.
  • correction — the $1/\mathrm{Re}_\lambda$ coefficient $a$.

GBGIsotropicTurbulence.Phenomenology.Scalings.Sreenivasan1995 — Type
Sreenivasan1995(; C_K = 1.5)

The three-dimensional Kolmogorov constant $C_K$ of the inertial-range energy spectrum

\[E(\kappa) = C_K \varepsilon^{2/3}\kappa^{-5/3},\]

the amplitude a Spectra model uses. Reviewing the experimental and numerical record, Sreenivasan (1995) found it close to universal. The default $C_K = 1.5 \pm 0.1$ used here is the consensus value as quoted by Sagaut & Cambon (2018), not a figure read off the 1995 paper, with no significant Reynolds-number trend; scaling(law, fp) returns it, independent of fp.

Fields

The plain constructor Sreenivasan1995(C_K) takes the field directly:

  • C_K — the Kolmogorov constant.

GBGIsotropicTurbulence.Phenomenology.Scalings.Li2008 — Type
Li2008(; dissipation_group = 0.9)

The box-normalized dissipation group

\[G = \frac{k}{(L\varepsilon)^{2/3}} \approx 0.9,\]

relating the turbulent kinetic energy $k$, the periodic-box side length $L$, and the dissipation rate $\varepsilon$ — nearly Reynolds-number-independent. The author–year handle names the dataset's source — Li et al. (2008) is the JHTDB paper — while the value is this package's own reduction of that database's forced-isotropic dataset ($\mathrm{Re}_\lambda \approx 433$), consistent with higher-Reynolds-number periodic-box DNS. The calibration is that single point: a low-Reynolds-number box — the small grids a smoke test reaches — uses this constant as an extrapolation. Its Reference records a conservative validity floor of $\mathrm{Re}_\lambda = 100$ below the calibration point; Reference's advisory-only contract still applies, and the grid-mode $\nu$ solve that consumes the law inherits the same standing.

The dissipation_group is the group value $G$ (default 0.9); scaling(law, fp) returns it. Inverted, stationary_dissipation(law, kinetic_energy, side_length) predicts the dissipation a stationary run of energy $k$ in a box $L$ sustains, $\varepsilon = (k/G)^{3/2}/L$ — the seam the run layer uses to set the viscosity from the grid and target energy.

$G$ is a distinct group from the classical dissipation anomaly $C_\varepsilon = \varepsilon L_{11}/u'^3$ (Taylor 1935, Proc. R. Soc. A 151, 421–444, doi:10.1098/rspa.1935.0158; Sreenivasan 1998, doi:10.1063/1.869575; Kaneda et al. 2003, doi:10.1063/1.1539855, for the periodic box), whose high-Reynolds-number plateau $C_\varepsilon \approx 0.5$ is normalized on the integral scale $L_{11}$, not the box side $L$.

On a common length the two are exactly related by $G = \tfrac{3}{2} C_\varepsilon^{-2/3}$ (using $u'^2 = 2k/3$). The quoted values, however, sit at different lengths ($L/L_{11} \approx 5$), so they must not be substituted into that identity directly — and, as fits to different datasets, they need not close exactly: carrying $C_\varepsilon \approx 0.5$ across at that ratio gives $G \approx 0.81$ against the quoted $0.9$.

Fields

The plain constructor Li2008(dissipation_group) takes the field directly:

  • dissipation_group — the group value $G$.

Predicting dissipation

Invert a box-normalized dissipation law to the dissipation a stationary run sustains — the seam the run layer uses to set the viscosity from the grid and target energy.

GBGIsotropicTurbulence.Phenomenology.Scalings.stationary_dissipation — Function
stationary_dissipation(law, kinetic_energy, side_length) -> Float64

The dissipation rate $\varepsilon$ a stationary run sustains, predicted by a box-normalized dissipation law from the turbulent kinetic energy $\texttt{kinetic\_energy} \equiv k$ and the periodic-box side length $\texttt{side\_length} \equiv L$ — the inverse of the law's scaling group (each law owns its own inverse; Li2008 gives the $(k/G)^{3/2}/L$ form). This is the seam by which a run's viscosity can be set from its grid and target energy, rather than the reverse.
