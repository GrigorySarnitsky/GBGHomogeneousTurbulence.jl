SimulationDomain

GBGIsotropicTurbulence.SimulationDomain — Module
SimulationDomain

The discretised periodic box a run lives on — the reusable, read-only frame:

  • FixedDomain — the fixed, unsheared cubic box (grid, transform plans, spectral multipliers, squared-wavenumber field, de-alias kernel).
  • DealiasingStrategy — the aliasing-control strategy, TwoThirds or HouLi, and the cutoff it sets, max_wavenumber.
  • spectral_vector, scalar_spectral, … — the field-sized scratch allocators.
  • dealias! — apply the de-alias kernel to a field in spectral representation, in place.

Precision and backend enter here and flow everywhere from here.

The discretised box

The reusable, read-only frame every buffer is allocated from — the FixedDomain, a fixed, unsheared periodic cube (a sheared frame is deferred).

GBGIsotropicTurbulence.SimulationDomain.FixedDomain — Type
FixedDomain(grid_points_per_axis, side_length = 2π; dealiasing = TwoThirds(),
                  scalar_type = Float64, array_type = Array)

The discretised periodic box a run lives on — the reusable, read-only frame: a cube of side length side_length sampled with grid_points_per_axis points along each axis, holding everything the pseudospectral method needs on that box.

Arguments

  • grid_points_per_axis — grid points $N$ along each axis (the box is $N^{3}$).
  • side_length = 2π — the physical side length $L$ (the box is $[0,L)^{3}$).
  • dealiasing = TwoThirds() — the de-aliasing strategy, TwoThirds (the sharp $2/3$ rule, the default) or HouLi (the smooth Hou–Li filter), applied by dealias! as a coefficientwise multiply to control the aliasing of the quadratic nonlinearity; it also sets the advective-CFL ceiling through recommended_cfl.
  • scalar_type = Float64 — the real element type (Float32 is GPU-friendly).
  • array_type = Array — the storage backend: Array (CPU) or CuArray / ROCArray (GPU).

Fields

  • grid, layout — the Grid3D and its real–Fourier memory layout.
  • velocity_plans, scalar_plans, tensor_plans — the real-to-complex transform plans, one per field rank: the velocity (a vector field), the scalar (a scalar field), and the rank-2 strain tensor the derivative-skewness diagnostic needs.
  • multipliers — the FieldSpectralMultipliers, the spectral first-derivative operators.
  • squared_wavenumber, squared_wavenumber_kernel — $\lvert\boldsymbol{\kappa}\rvert^{2}$ (in spectral representation $-\nabla^{2}$ acts as multiplication by it), kept both as a real array and as a scalar-field kernel for weighted spectral reductions.
  • dealias, dealiasing — the de-alias kernel and the DealiasingStrategy that built it.

De-aliasing strategies

The aliasing-control strategy passed to FixedDomain — the supertype, then the sharp 2/3-rule default and the smooth Hou–Li filter.

GBGIsotropicTurbulence.SimulationDomain.DealiasingStrategy — Type
DealiasingStrategy

How the aliasing of the quadratic nonlinearity is controlled. A FixedDomain is built with one; it fixes the domain.dealias kernel and, through recommended_cfl, the advective-CFL ceiling. Concrete strategies: TwoThirds (the sharp $2/3$ rule, the default) and HouLi (the smooth Hou–Li filter).

source
GBGIsotropicTurbulence.SimulationDomain.TwoThirds — Type
TwoThirds()

The sharp isotropic $2/3$-rule truncation: keep the modes $\kappa \le \kappa_{\max} = \tfrac23\kappa_{\mathrm{Ny}}$ and zero the rest, where $\kappa_{\mathrm{Ny}} = \tfrac N2\cdot\tfrac{2\pi}{L}$ is the Nyquist wavenumber and $\kappa_{\max}$ the dealiased maximum — two-thirds of the way out to Nyquist. Exact de-aliasing of the quadratic nonlinearity, and the lean, GPU-friendly default.

source
GBGIsotropicTurbulence.SimulationDomain.HouLi — Type
HouLi(; order = 36, strength = nothing)

The smooth Hou–Li spectral filter, transfer function $\exp\!\big(-\,\texttt{strength}\,(\kappa/\kappa_{\mathrm{Ny}})^{\texttt{order}}\big)$, with $\kappa_{\mathrm{Ny}} = \tfrac N2\cdot\tfrac{2\pi}{L}$ the Nyquist wavenumber. The order sets the sharpness of the spectral roll-off (higher is closer to a sharp cutoff); the strength sets the damping at the Nyquist mode, which is multiplied by $\mathrm{e}^{-\texttt{strength}}$. By default (strength = nothing) strength is chosen for the domain's element type as $-\log$ of its machine epsilon — $\approx 36$ for Float64, $\approx 16$ for Float32 — so the Nyquist mode always damps to that precision's machine epsilon; pass an explicit strength to override. It keeps more modes than the $2/3$ rule but only damps aliasing rather than removing it exactly — a stabilisation, hence an opt-in, not the default. Applied isotropically in $\kappa$. Because it retains energy out to the Nyquist wavenumber it takes a proportionally smaller CFL step than the $2/3$ rule — handled automatically by recommended_cfl.

source

The de-aliasing cutoff it sets — the highest wavenumber the domain evolves, and the resolution criterion $\kappa_{\max}\eta$ a run is built to meet.

GBGIsotropicTurbulence.SimulationDomain.max_wavenumber — Function
max_wavenumber(domain)

The highest wavenumber magnitude that domain actually evolves — the de-aliasing cutoff

\[\kappa_{\max} = f\,\frac N2\,\frac{2\pi}{L},\]

with $N$ the resolution, $L$ the box side, and $f$ the retained-Nyquist fraction of the DealiasingStrategy ($2/3$ for TwoThirds, $1$ for HouLi). It is the cutoff the de-aliasing sets — not the grid Nyquist $\tfrac N2\tfrac{2\pi}{L}$ itself; the modes above it are zeroed each step. It fixes both the advective-CFL step (recommended_cfl) and the resolution criterion $\kappa_{\max}\eta$ that a run is set up to meet.

De-alias filtering

Apply the domain's de-alias low-pass kernel to a spectral field in place.

GBGIsotropicTurbulence.SimulationDomain.dealias! — Function
dealias!(field, domain)

Apply the run's de-alias low-pass domain.dealias to field in place — a coefficientwise multiply that controls the aliasing of the quadratic nonlinearity. The kernel is whatever the run's DealiasingStrategy built: the sharp $2/3$ cutoff (TwoThirds, exact de-aliasing) or the smooth HouLi filter (which only damps the aliasing). The field may be a vector or scalar field in spectral representation.
