Spectra

GBGIsotropicTurbulence.Phenomenology.Spectra — Module
Phenomenology.Spectra

Model spectra — parametrizations of the reference velocity spectrum $E(\kappa)$ and the scalar spectrum $E_\varphi(\kappa)$, evaluated by spectrum. A velocity model is composed: an inertial-range core $C_K\varepsilon^{2/3}\kappa^{-5/3}$ times a large-scale roll-off and a dissipation-range roll-off, each swappable.

  • ModelSpectrum — the composed velocity spectrum: a Kolmogorov constant, a LargeScaleFactor, and a DissipationFactor.
  • LargeScaleFactor / DissipationFactor — the swappable roll-off pieces, evaluated by large_scale_factor / dissipation_factor: PopeLargeScale / PopeDissipation are Pope's forms, VonKarmanLarge the classic $\kappa^4$ energy range, and UnitDissipation is no cutoff.
  • Pope2000 / VonKarman1948 — named velocity-spectrum presets of ModelSpectrum.
  • ScalarSpectrum — the passive-scalar spectra; ObukhovCorrsin1949 is the inertial-convective range.

GBGIsotropicTurbulence.Phenomenology.Spectra.ModelSpectrum — Type
ModelSpectrum(C_K, large_scale, dissipation, ref)

The composed model energy spectrum

\[E(\kappa) = C_K\,\varepsilon^{2/3}\,\kappa^{-5/3}\,f_L(\kappa L)\,f_\eta(\kappa\eta),\]

an inertial-range core with Kolmogorov constant C_K times a large-scale roll-off large_scale (a LargeScaleFactor, giving $f_L$) and a dissipation-range roll-off dissipation (a DissipationFactor, giving $f_\eta$); ref is its Reference. Build one directly to mix roll-off forms, or use a preset such as Pope2000. Evaluated by spectrum(model, κ, fp), which reads $\varepsilon$ and $L$ from fp and forms $\eta$ with kolmogorov_length.

Roll-off factors

The swappable large-scale and dissipation-range shapes, and Pope's forms.

GBGIsotropicTurbulence.Phenomenology.Spectra.LargeScaleFactor — Type
LargeScaleFactor

Supertype of the dimensionless large-scale roll-off factors $f_L(\kappa L)$ of a composed ModelSpectrum — the shape that bends the inertial $\kappa^{-5/3}$ law over into the energy-containing range, with $f_L \to 1$ as $\kappa L \to \infty$. Evaluated by large_scale_factor; PopeLargeScale is Pope's form.

source
GBGIsotropicTurbulence.Phenomenology.Spectra.DissipationFactor — Type
DissipationFactor

Supertype of the dimensionless dissipation-range roll-off factors $f_\eta(\kappa\eta)$ of a composed ModelSpectrum — the shape that cuts the spectrum off near the Kolmogorov scale, with $f_\eta \to 1$ as $\kappa\eta \to 0$. Evaluated by dissipation_factor; PopeDissipation is Pope's form.

source
GBGIsotropicTurbulence.Phenomenology.Spectra.PopeLargeScale — Type
PopeLargeScale(c_L, p₀)

Pope's large-scale roll-off $f_L(\kappa L) = \left(\dfrac{\kappa L}{\sqrt{(\kappa L)^2 + c_L}}\right)^{5/3 + p_0}$, which tends to 1 in the inertial range and rolls the spectrum off below the integral scale. c_L is set by the requirement that the spectrum integrate to the kinetic energy; p₀ fixes the low-wavenumber slope (Pope 2000).

source
GBGIsotropicTurbulence.Phenomenology.Spectra.PopeDissipation — Type
PopeDissipation(c_η, β)

Pope's dissipation-range roll-off $f_\eta(\kappa\eta) = \exp\!\big(-\beta\{[(\kappa\eta)^4 + c_\eta^4]^{1/4} - c_\eta\}\big)$, which tends to 1 in the inertial range and cuts the spectrum off near the Kolmogorov scale. c_η is set by the requirement that the spectrum yield the dissipation rate; β fixes the sharpness of the cutoff (Pope 2000).

source
GBGIsotropicTurbulence.Phenomenology.Spectra.VonKarmanLarge — Type
VonKarmanLarge(c_L)

The von Kármán large-scale roll-off $f_L(\kappa L) = \left(\dfrac{(\kappa L)^2}{(\kappa L)^2 + c_L}\right)^{17/6}$, which tends to 1 in the inertial range and produces the classic $\kappa^4$ energy-containing range at low wavenumber ($E \sim \kappa^{-5/3}f_L \sim \kappa^4$); c_L fixes the peak scale (von Kármán 1948).

source
GBGIsotropicTurbulence.Phenomenology.Spectra.UnitDissipation — Type
UnitDissipation()

The trivial dissipation-range factor $f_\eta \equiv 1$ — no viscous cutoff, for a spectrum defined only over the energy-containing and inertial ranges (the classic VonKarman1948 form).

Velocity models

The named velocity-spectrum presets of the composed ModelSpectrum.

GBGIsotropicTurbulence.Phenomenology.Spectra.Pope2000 — Function
Pope2000(; C_K = 1.5, c_L = 6.78, p₀ = 2.0, c_η = 0.40, β = 5.2)

The Pope (2000) model spectrum — a preset ModelSpectrum with PopeLargeScale and PopeDissipation roll-offs:

\[E(\kappa) = C_K\,\varepsilon^{2/3}\,\kappa^{-5/3}\,f_L(\kappa L)\,f_\eta(\kappa\eta).\]

C_K is the Kolmogorov constant; the defaults c_L = 6.78, c_η = 0.40 are the high-Reynolds-number values Pope obtains from the energy and dissipation normalizations, with the shape exponents p₀ = 2 and β = 5.2. Override any coefficient to re-fit. Evaluate with spectrum(Pope2000(), κ, fp).

source
GBGIsotropicTurbulence.Phenomenology.Spectra.VonKarman1948 — Function
VonKarman1948(; C_K = 1.5, c_L = 1.0)

The von Kármán (1948) energy spectrum — a preset ModelSpectrum with the VonKarmanLarge roll-off and no viscous cutoff (UnitDissipation):

\[E(\kappa) = C_K\,\varepsilon^{2/3}\,\kappa^{-5/3} \left(\frac{(\kappa L)^2}{(\kappa L)^2 + c_L}\right)^{17/6},\]

the classic interpolation between the $\kappa^4$ energy-containing range and the $\kappa^{-5/3}$ inertial range, with no dissipation-range cutoff (use Pope2000 when the cutoff matters). C_K is the Kolmogorov constant; c_L fixes the peak scale.

Scalar spectra

The passive-scalar spectrum models.

GBGIsotropicTurbulence.Phenomenology.Spectra.ScalarSpectrum — Type
ScalarSpectrum <: TurbulenceLaw

Supertype of the passive-scalar spectrum models — parametrizations of $E_\varphi(\kappa)$, the density in wavenumber of the scalar variance $\langle\varphi^2\rangle$, evaluated by spectrum. ObukhovCorrsin1949 is the inertial-convective range.

source
GBGIsotropicTurbulence.Phenomenology.Spectra.ObukhovCorrsin1949 — Type
ObukhovCorrsin1949(; C_OC = 0.67)

The Obukhov–Corrsin inertial-convective scalar spectrum

\[E_\varphi(\kappa) = C_{OC}\,\varepsilon_\varphi\,\varepsilon^{-1/3}\,\kappa^{-5/3},\]

the scalar analogue of the Kolmogorov $-5/3$ law: for a Schmidt number of order one the scalar's inertial-convective range coincides with the velocity inertial range. C_OC is the Obukhov–Corrsin constant ($\approx 0.67$ for the three-dimensional spectrum). spectrum reads the scalar dissipation $\varepsilon_\varphi$ (fp.scalar_dissipation, which must be set) and the kinetic-energy dissipation $\varepsilon$ from fp.
