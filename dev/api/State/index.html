State

GBGIsotropicTurbulence.State — Module
State

The evolving state a run advances, its derived views, and how it is seeded:

  • ResolvedFields — the inert record of the evolving velocity and scalar in spectral representation (the single source of truth; the physical fields are derived, never stored).
  • velocity_to_physical!, vorticity_to_physical!, scalar_to_physical! — recover the velocity, vorticity, and scalar in physical representation from the spectral state.
  • DerivedFields — the observation cache: stamped, memoized derived fields with recompute-on-staleness accessors.
  • physical_velocity, physical_vorticity — the sanctioned reads of the cached velocity and vorticity in physical representation.
  • resolved_fields_modified! — declare an out-of-band state mutation so every cached chart is recomputed on its next read; spectral_scratch — the cache's spectral working space.
  • random_solenoidal_velocity! and random_scalar! — the random initial conditions (a divergence-free velocity, a mean-zero scalar) that seed it.

All sized to a FixedDomain.

The state

The evolving fields a run advances, in spectral representation — the single source of truth.

GBGIsotropicTurbulence.State.ResolvedFields — Type
ResolvedFields(domain; scalar = false)

The inert record of the evolving fields a run advances, in spectral representation — the single source of truth, from which the velocity, vorticity, and scalar in physical representation are derived on demand and never stored, so the state cannot go stale. Build it on a FixedDomain; pass scalar = true to carry a passive scalar.

Fields

  • velocity — the velocity in spectral representation, $\hat{\boldsymbol{u}}$.
  • scalar — the scalar in spectral representation, $\hat\varphi$, or nothing when the run carries no passive scalar.

vorticity_to_physical!(ω, û, domain, spectral_scratch)

The observation cache

Stamped, memoized derived fields with recompute-on-staleness accessors — the sanctioned way for a reader (a diagnostic, a particle push, a statistics callback) to the physical representations the time loop would otherwise compute and discard.

GBGIsotropicTurbulence.State.DerivedFields — Type
DerivedFields(domain; charts = (:velocity, :vorticity))

The observation cache of a run — preallocated, stamped, memoized derived fields, giving every reader (a diagnostic, a particle push, a statistics callback) a sanctioned way to the physical representations the time loop would otherwise compute and discard. Each chart slot holds a derived field's values — on the grid lattice, or (for future trajectory-bound charts) at the tracer positions; particle content never enters. An accessor (physical_velocity, physical_vorticity) returns the stored field when it is current for the present state and recomputes it first otherwise, so a stale read is impossible.

Build the cache on a FixedDomain; charts names the slots to allocate — resident memory is opt-in, and reading a chart that was not declared is an error. The available charts are :velocity (the velocity $\boldsymbol{u}$ in physical representation) and :vorticity (the vorticity $\boldsymbol{\omega} = \nabla\times\boldsymbol{u}$ in physical representation).

Freshness

The cache carries one epoch counter per dynamical factor of the run — fields_epoch for the resolved fields (advanced by every completed step!, and by resolved_fields_modified! after an out-of-band mutation) and particles_epoch for the tracers (reserved for trajectory-bound charts). A slot's stamp records the epoch it was computed at; a stamp behind the epoch marks the slot stale, and the accessor recomputes and restamps it on the next read.

Fields

  • charts — a NamedTuple of the allocated slots; each slot holds the derived field's preallocated storage and its stamp.
  • spectral_scratch — the cache's spectral working space (see spectral_scratch).
  • fields_epoch, particles_epoch — the per-factor epoch counters.

GBGIsotropicTurbulence.State.physical_velocity — Function
physical_velocity(derived, state, domain)
physical_velocity(sim)

The velocity $\boldsymbol{u}$ in physical representation, current for the state — the sanctioned read of the derived velocity field. When the DerivedFields derived's :velocity chart is already current (its stamp matches the fields epoch) the stored field is returned as is; otherwise it is first recomputed from the spectral $\hat{\boldsymbol{u}}$ of state (a ResolvedFields) by velocity_to_physical! on the FixedDomain domain, and restamped. Treat the returned field as read-only: it is the cache's storage, shared by every reader until the fields next advance. The second form reads a Simulation's cache, state, and domain.

GBGIsotropicTurbulence.State.physical_vorticity — Function
physical_vorticity(derived, state, domain)
physical_vorticity(sim)

The vorticity $\boldsymbol{\omega} = \nabla\times\boldsymbol{u}$ in physical representation, current for the state — the sanctioned read of the derived vorticity field, memoized exactly as physical_velocity (recomputed by vorticity_to_physical! when stale, returned as is when current; treat as read-only). The second form reads a Simulation's cache, state, and domain.

GBGIsotropicTurbulence.State.resolved_fields_modified! — Function
resolved_fields_modified!(derived)
resolved_fields_modified!(sim)

Declare that the resolved fields — the spectral $\hat{\boldsymbol{u}}$, $\hat\varphi$ — were changed outside the sanctioned propagators (a re-seeded velocity, any direct write to the state's storage), so every derived chart is stale and will be recomputed on its next read. Advances the cache's fields epoch and returns derived.

The sanctioned mutators call this for you: step! advances the epoch itself when it completes. A hand-run loop that mutates the spectral state directly must call it — a forgotten call leaves the charts serving the previous fields, the one staleness the cache cannot detect on its own.

GBGIsotropicTurbulence.State.spectral_scratch — Function
spectral_scratch(derived)

The observation cache's working space in spectral representation (a vector field) — the scratch the chart recomputations, and the run layer's spectral reductions, write through. Its contents are undefined between operations: any single operation may use it freely; nothing may store into it across operations.

Random initial conditions

Seed a large-scale-peaked, dealiased, rescaled random solenoidal velocity, or a mean-zero scalar.

GBGIsotropicTurbulence.State.random_solenoidal_velocity! — Function
random_solenoidal_velocity!(û, domain; kinetic_energy, peak_wavenumber,
                            spectrum = nothing, rng = default_rng())

Fill û (a velocity field in spectral representation) with a random, divergence-free velocity $\boldsymbol{u}$ of a chosen energy spectrum, dealiased and rescaled so the kinetic energy $\tfrac{1}{2}\langle\lvert\boldsymbol{u}\rvert^{2}\rangle$ equals kinetic_energy. The Leray–Helmholtz projection $\mathbb{P}$ enforces $\nabla\cdot\boldsymbol{u} = 0$.

By default (spectrum = nothing) the velocity is concentrated at large scales by a Gaussian envelope $\exp\!\big(-\lvert\boldsymbol{\kappa}\rvert^{2}/\kappa_p^{2}\big)$ on the mode amplitudes, whose characteristic wavenumber is $\kappa_p$ (peak_wavenumber). Because the envelope multiplies the amplitudes, the shell-summed energy spectrum $\propto \kappa^{2}\exp\!\big(-2\kappa^{2}/\kappa_p^{2}\big)$ peaks at $\kappa_p/\sqrt{2}$, not at $\kappa_p$ itself (the $\kappa^{2}$ is the shell's mode count). Pass spectrum, a function $\kappa \mapsto E(\kappa)$ giving a target radial energy spectrum, to seed that shape instead: each mode is scaled by $\sqrt{E(\kappa)}/\kappa$, so the shell-summed spectrum is $\propto \kappa^{2}(\sqrt{E}/\kappa)^{2} = E(\kappa)$ (the $\kappa^{2}$ is the shell's mode count) and the overall amplitude is fixed by the kinetic_energy rescaling — e.g. a von Kármán or Pope form from the Phenomenology submodule's model spectra, which the run layer can wire in for you.

The domain (a FixedDomain) is what the field is generated on; the rng is the random stream (defaults to Random.default_rng()).

Note

Seeding into a running case mutates the resolved fields out of band — follow it with resolved_fields_modified! so the derived charts are recomputed on their next read.

GBGIsotropicTurbulence.State.random_scalar! — Function
random_scalar!(φ̂, domain; scalar_variance, peak_wavenumber,
               spectrum = nothing, rng = default_rng())

Fill φ̂ (the scalar $\varphi$ in spectral representation) with a random, mean-zero scalar of a chosen spectrum, dealiased and rescaled so the variance $\langle\varphi^{2}\rangle$ equals scalar_variance. The noise is made mean-zero in physical space before the transform, so the $\boldsymbol{\kappa}=\boldsymbol 0$ (mean) mode vanishes.

By default (spectrum = nothing) the scalar is concentrated at large scales by a Gaussian envelope $\exp\!\big(-\lvert\boldsymbol{\kappa}\rvert^{2}/\kappa_p^{2}\big)$ on the mode amplitudes, whose characteristic wavenumber is $\kappa_p$ (peak_wavenumber). Because the envelope multiplies the amplitudes, the shell-summed scalar-variance spectrum $\propto \kappa^{2}\exp\!\big(-2\kappa^{2}/\kappa_p^{2}\big)$ peaks at $\kappa_p/\sqrt{2}$, not at $\kappa_p$ itself (the $\kappa^{2}$ is the shell's mode count). Pass spectrum, a function $\kappa \mapsto E_\varphi(\kappa)$ giving a target radial scalar-variance spectrum, to seed that shape instead: each mode is scaled by $\sqrt{E_\varphi(\kappa)}/\kappa$ (the same construction the velocity uses), so the shell-summed spectrum is $\propto E_\varphi(\kappa)$ and the amplitude is fixed by the scalar_variance rescaling — e.g. an Obukhov–Corrsin form from Phenomenology.

The domain (a FixedDomain) is what the field is generated on; the rng is the random stream (defaults to Random.default_rng()).

Note

Seeding into a running case mutates the resolved fields out of band — follow it with resolved_fields_modified! so the derived charts are recomputed on their next read.
