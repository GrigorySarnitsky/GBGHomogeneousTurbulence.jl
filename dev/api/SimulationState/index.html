GBGIsotropicTurbulence.SimulationState — Module
SimulationState

The spectral machinery and preallocated buffers a run advances: SpectralOperators (the read-only grid, transform plans, multipliers, squared-wavenumber field, and de-alias kernel), the scratch allocators, Workspace, and the random divergence-free initial condition.

Public API

GBGIsotropicTurbulence.SimulationState.DealiasingStrategy — Type
DealiasingStrategy

How the aliasing of the quadratic nonlinearity is controlled. A SpectralOperators is built with one; it fixes the ops.dealias kernel and, through recommended_cfl, the advective-CFL ceiling. Concrete strategies: TwoThirds (the sharp $2/3$ rule, the default) and HouLi (the smooth Hou–Li filter).

GBGIsotropicTurbulence.SimulationState.HouLi — Type
HouLi(; order = 36, strength = 36)

The smooth Hou–Li spectral filter, transfer function $\exp\!\big(-\,\texttt{strength}\,(\kappa/\kappa_{\max})^{\texttt{order}}\big)$ (defaults $36, 36$, damping the Nyquist mode to $\mathrm{e}^{-36}\approx$ machine epsilon). It keeps more modes than the $2/3$ rule but only damps aliasing rather than removing it exactly — a stabilisation, hence an opt-in, not the default. Applied isotropically in $\kappa$ (the filter TurTLE uses, there per-axis). Because it retains energy out to the Nyquist wavenumber it takes a proportionally smaller CFL step than the $2/3$ rule — handled automatically by recommended_cfl.

GBGIsotropicTurbulence.SimulationState.SpectralOperators — Type
SpectralOperators(resolution, box = 2π; dealiasing = TwoThirds(),
                  scalar_type = Float64, array_type = Array)

The reusable, read-only spectral machinery for a cubic homogeneous-isotropic-turbulence run on a grid of resolution points per side, in a periodic box of side box: the Grid3D, the real-to-complex transform plans (one for the velocity, a vector field; one for the scalar $\varphi$), the FieldSpectralMultipliers, the squared-wavenumber array $\lvert\boldsymbol{\kappa}\rvert^{2}$ (with $\boldsymbol{\kappa}$ the wavenumber vector — the symbol of $-\nabla^{2}$), and the de-alias kernel dealias.

dealias is built by the dealiasing strategy — TwoThirds (the sharp $2/3$ rule, the default) or HouLi (the smooth Hou–Li filter). Both are applied by dealias! as a coefficientwise multiply to control the aliasing error of the quadratic nonlinearity; the choice also sets the advective-CFL ceiling through recommended_cfl.

array_type selects the storage backend (Array for CPU, ROCArray/CuArray for GPU) and scalar_type the real element type (Float32 is GPU-friendly).

GBGIsotropicTurbulence.SimulationState.TwoThirds — Type
TwoThirds()

The sharp isotropic $2/3$-rule truncation: keep the modes $\kappa \le \tfrac23 \kappa_{\max}$ and zero the rest ($\kappa_{\max}$ the Nyquist wavenumber). Exact de-aliasing of the quadratic nonlinearity, and the lean, GPU-friendly default.

source
GBGIsotropicTurbulence.SimulationState.Workspace — Type
Workspace(ops)

Preallocated scratch for one coupled integrating-factor step of the velocity and the passive scalar $\varphi$. The velocity buffers are the spectral vorticity, two Runge–Kutta stage registers, the predictor field, a velocity copy (the in-place inverse transform consumes its source), a general spectral scratch, the nonlinear-term buffer, and the physical velocity / vorticity / predictor / Lamb-vector ($\boldsymbol{u}\times\boldsymbol{\omega}$). The scalar buffers are two stage registers, a predictor, the nonlinear-term buffer, a copy, the shared integrating factor, and the physical scalar; the scalar flux $\boldsymbol{u}\varphi$ reuses the physical and spectral velocity scratch. Sized so a step allocates no field-sized memory.

GBGIsotropicTurbulence.SimulationState.random_scalar! — Method
random_scalar!(phih, ops; variance = 1.0, peak_wavenumber = 2.0, rng = default_rng())

Fill phih (the scalar $\varphi$ in spectral representation) with a random, mean-zero scalar concentrated at large scales by the envelope $\exp\!\big(-\lvert\boldsymbol{\kappa}\rvert^{2}/k_p^{2}\big)$ ($k_p$ is peak_wavenumber), de-aliased, and rescaled so the variance $\langle\varphi^{2}\rangle$ equals variance. The physical noise is made mean-zero before the transform, so the $\boldsymbol{\kappa}=\boldsymbol 0$ (mean) mode vanishes.

GBGIsotropicTurbulence.SimulationState.random_solenoidal_velocity! — Method
random_solenoidal_velocity!(uh, ops; energy = 0.5, peak_wavenumber = 2.0, rng = default_rng())

Fill uh (a velocity field in spectral representation) with a random, divergence-free velocity $\boldsymbol{u}$ concentrated at large scales by the envelope $\exp\!\big(-\lvert\boldsymbol{\kappa}\rvert^{2}/k_p^{2}\big)$ ($k_p$ is peak_wavenumber), de-aliased, and rescaled so the kinetic energy $\tfrac12\langle\lvert\boldsymbol{u}\rvert^{2}\rangle$ equals energy. The Leray–Helmholtz projection $\mathbb{P}$ enforces $\nabla\cdot\boldsymbol{u} = 0$.
