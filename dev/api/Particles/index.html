Particles

GBGIsotropicTurbulence.Particles — Module
Particles

Lagrangian tracer tracking: Tracers (positions + a selectable interpolation scheme), the second-order advect! (Heun-in-time on the start- and end-of-step velocity), and sample! for reading a field along the trajectories.

Trajectory readouts are tracer_positions, tracer_velocities, and ntracers; velocity_buffer / scalar_buffer allocate the out buffers for sample!.

source

The tracer set

Tracer positions plus a pluggable interpolation scheme, preallocated for allocation-free advection.

GBGIsotropicTurbulence.Particles.Tracers — Type
Tracers(domain, count; scheme = CatmullRom, rng = default_rng())
Tracers(positions; scheme = CatmullRom)

A set of Lagrangian tracers. The first form seeds count tracers uniformly at random in the periodic box of domain (on the domain's backend and element type); the second wraps a given (M, 3) position array. The scheme is the GBGPeriodicFields interpolation scheme used to evaluate the velocity (and any sampled field) at the tracer positions — CatmullRom (the default), LalescuSpline(n, m), or LagrangeSpline(n). The rng (first form only) is the random stream seeding the uniformly-random tracer positions; it defaults to Random.default_rng().

Read the tracer state with tracer_positions, tracer_velocities, and ntracers; the remaining fields are preallocated predictor and point-value scratch, so advect! allocates no per-step memory.

Advection and sampling

Second-order Heun-in-time advection, and reading a physical field along the trajectories.

GBGIsotropicTurbulence.Particles.advect! — Function
advect!(tracers, velocity_start, velocity_end, domain, dt) -> tracers

Advance the tracer positions by one step of size dt, in place, by Heun-in-time on the physical velocity fields at the start (velocity_start $= \boldsymbol{u}(t_n)$) and end (velocity_end $= \boldsymbol{u}(t_{n+1})$) of the step:

\[\boldsymbol{v}_1 = \boldsymbol{u}(t_n, \boldsymbol{X}), \quad \boldsymbol{X}^{*} = \boldsymbol{X} + \Delta t\,\boldsymbol{v}_1, \quad \boldsymbol{v}_2 = \boldsymbol{u}(t_{n+1}, \boldsymbol{X}^{*}), \quad \boldsymbol{X} \leftarrow \boldsymbol{X} + \tfrac{\Delta t}{2}(\boldsymbol{v}_1 + \boldsymbol{v}_2),\]

with positions wrapped into $[0, L)$, where the box side $L$ is read from domain (a FixedDomain). This is second-order accurate in time. The start-of-step velocity $\boldsymbol{v}_1$ is retained (tracer_velocities) as the trajectory velocity for the Lagrangian statistics.

source
GBGIsotropicTurbulence.Particles.sample! — Function
sample!(out, field, tracers) -> out

Sample the physical field at the current tracer positions into the point-value buffer out (a VectorPointValues for the velocity, a ScalarPointValues for the scalar $\varphi$), using the tracers' interpolation scheme. Used to gather a field along the trajectories for the Lagrangian statistics.
