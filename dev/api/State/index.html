State

GBGIsotropicTurbulence.State — Module
State

The DNS realisation of the Mori–Zwanzig State role — the field the dynamics acts on, as stored and seeded: FieldBuffers, the preallocated scratch a coupled velocity + scalar step writes into (only what the configured run needs; no scalar buffers when the run carries no scalar), and the random initial conditions random_solenoidal_velocity! (the divergence-free velocity) and random_scalar! (the mean-zero scalar $\varphi$). All sized to a FixedDomain.

Field buffers

The preallocated per-step scratch a run advances — allocated only for what the configured run needs (no scalar scratch when the run carries no scalar).

GBGIsotropicTurbulence.State.FieldBuffers — Type
FieldBuffers(domain; scalar = false)

Preallocated scratch for one integrating-factor step, sized so a step allocates no field-sized memory. The velocity buffers are the spectral vorticity, two Runge–Kutta stage registers (buffers holding a stage's state and accumulator), the predictor field, a velocity copy (the in-place inverse transform consumes its source), a general spectral scratch, the nonlinear-term buffer, and the physical velocity / start-of-step vorticity / per-stage vorticity / predictor / Lamb-vector ($\boldsymbol{u}\times\boldsymbol{\omega}$); the shared integrating factor and the velocity's per-mode linear-forcing-rate array $A(\boldsymbol{\kappa})$ complete them.

When scalar = true a ScalarBuffers bundle is allocated for the passive scalar $\varphi$ (two stage registers, a predictor, the nonlinear-term buffer, a copy, the physical scalar, and its forcing-rate array; the scalar flux $\boldsymbol{u}\varphi$ reuses the velocity scratch). When scalar = false the run evolves no scalar, so buffers.scalar is nothing and none of those field-sized buffers are allocated.

Random initial conditions

Seed a large-scale-peaked, de-aliased, rescaled random solenoidal velocity, or a mean-zero scalar φ.

GBGIsotropicTurbulence.State.random_solenoidal_velocity! — Function
random_solenoidal_velocity!(û, domain; energy = 0.5, peak_wavenumber = 2.0,
                            spectrum = nothing, rng = default_rng())

Fill û (a velocity field in spectral representation) with a random, divergence-free velocity $\boldsymbol{u}$ of a chosen energy spectrum, de-aliased and rescaled so the kinetic energy $\tfrac12\langle\lvert\boldsymbol{u}\rvert^{2}\rangle$ equals energy. The Leray–Helmholtz projection $\mathbb{P}$ enforces $\nabla\cdot\boldsymbol{u} = 0$.

By default (spectrum = nothing) the velocity is concentrated at large scales by the Gaussian envelope $\exp\!\big(-\lvert\boldsymbol{\kappa}\rvert^{2}/k_p^{2}\big)$ ($k_p$ is peak_wavenumber). Pass spectrum, a function $\kappa \mapsto E(\kappa)$ giving a target radial energy spectrum, to seed that shape instead: each mode is scaled by $\sqrt{E(\kappa)}/\kappa$, so the shell-summed spectrum is $\propto \kappa^{2}(\sqrt{E}/\kappa)^{2} = E(\kappa)$ (the $\kappa^{2}$ is the shell's mode count) and the overall amplitude is fixed by the energy rescaling. The run layer bridges a Phenomenology model spectrum into this function.

domain is the FixedDomain supplying the grid, backend, wavenumber multipliers, and de-alias kernel; rng is the random stream (defaults to Random.default_rng()).

GBGIsotropicTurbulence.State.random_scalar! — Function
random_scalar!(φ̂, domain; variance = 1.0, peak_wavenumber = 2.0,
               spectrum = nothing, rng = default_rng())

Fill φ̂ (the scalar $\varphi$ in spectral representation) with a random, mean-zero scalar of a chosen spectrum, de-aliased and rescaled so the variance $\langle\varphi^{2}\rangle$ equals variance. The physical noise is made mean-zero before the transform, so the $\boldsymbol{\kappa}=\boldsymbol 0$ (mean) mode vanishes.

By default (spectrum = nothing) the scalar is concentrated at large scales by the Gaussian envelope $\exp\!\big(-\lvert\boldsymbol{\kappa}\rvert^{2}/k_p^{2}\big)$ ($k_p$ is peak_wavenumber). Pass spectrum, a function $\kappa \mapsto E_\varphi(\kappa)$ giving a target radial scalar-variance spectrum, to seed that shape instead: each mode is scaled by $\sqrt{E_\varphi(\kappa)}/\kappa$ (the same construction the velocity uses), so the shell-summed spectrum is $\propto E_\varphi(\kappa)$ and the amplitude is fixed by the variance rescaling — e.g. an Obukhov–Corrsin form from Phenomenology.

domain is the FixedDomain supplying the grid, backend, wavenumber multipliers, and de-alias kernel; rng is the random stream (defaults to Random.default_rng()).
