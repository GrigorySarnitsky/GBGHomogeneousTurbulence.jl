GBGIsotropicTurbulence.State — Module
State

The DNS realisation of the Mori–Zwanzig State role — the field the dynamics acts on and how it is seeded: ResolvedFields, the inert record of the evolving spectral velocity and scalar (the single source of truth — the physical fields are derived, never stored), and the random initial conditions random_solenoidal_velocity! (the divergence-free velocity) and random_scalar! (the mean-zero scalar) that seed it. All sized to a FixedDomain.

The state

The inert record of the evolving spectral fields a run advances — the single source of truth (velocity û and, optionally, scalar φ̂); the physical velocity, vorticity, and scalar are derived on demand, never stored.

GBGIsotropicTurbulence.State.ResolvedFields — Type
ResolvedFields(domain; scalar = false)

The inert record of the evolving spectral fields a run advances — the Mori–Zwanzig state, and the single source of truth: the spectral velocity $\hat{\boldsymbol u}$ (velocity) and, when the run carries a passive scalar, the spectral scalar $\hat\varphi$ (scalar; nothing otherwise). The physical velocity, vorticity, and scalar are derived from these on demand, never stored here — so the state cannot go stale. No operation hangs on this record: the generator advances it and the observables read it as external functions of $(\hat{\boldsymbol u}, \hat\varphi)$. Allocated on a FixedDomain.

Random initial conditions

Seed a large-scale-peaked, de-aliased, rescaled random solenoidal velocity, or a mean-zero scalar φ.

GBGIsotropicTurbulence.State.random_solenoidal_velocity! — Function
random_solenoidal_velocity!(û, domain; energy = 0.5, peak_wavenumber = 2.0,
                            spectrum = nothing, rng = default_rng())

Fill û (a velocity field in spectral representation) with a random, divergence-free velocity $\boldsymbol{u}$ of a chosen energy spectrum, de-aliased and rescaled so the kinetic energy $\tfrac12\langle\lvert\boldsymbol{u}\rvert^{2}\rangle$ equals energy. The Leray–Helmholtz projection $\mathbb{P}$ enforces $\nabla\cdot\boldsymbol{u} = 0$.

By default (spectrum = nothing) the velocity is concentrated at large scales by the Gaussian envelope $\exp\!\big(-\lvert\boldsymbol{\kappa}\rvert^{2}/k_p^{2}\big)$ ($k_p$ is peak_wavenumber). Pass spectrum, a function $\kappa \mapsto E(\kappa)$ giving a target radial energy spectrum, to seed that shape instead: each mode is scaled by $\sqrt{E(\kappa)}/\kappa$, so the shell-summed spectrum is $\propto \kappa^{2}(\sqrt{E}/\kappa)^{2} = E(\kappa)$ (the $\kappa^{2}$ is the shell's mode count) and the overall amplitude is fixed by the energy rescaling — e.g. a von Kármán or Pope form from the Phenomenology submodule's model spectra, which the run layer can wire in for you.

domain is the FixedDomain the field is generated on; rng is the random stream (defaults to Random.default_rng()).

GBGIsotropicTurbulence.State.random_scalar! — Function
random_scalar!(φ̂, domain; variance = 1.0, peak_wavenumber = 2.0,
               spectrum = nothing, rng = default_rng())

Fill φ̂ (the scalar $\varphi$ in spectral representation) with a random, mean-zero scalar of a chosen spectrum, de-aliased and rescaled so the variance $\langle\varphi^{2}\rangle$ equals variance. The physical noise is made mean-zero before the transform, so the $\boldsymbol{\kappa}=\boldsymbol 0$ (mean) mode vanishes.

By default (spectrum = nothing) the scalar is concentrated at large scales by the Gaussian envelope $\exp\!\big(-\lvert\boldsymbol{\kappa}\rvert^{2}/k_p^{2}\big)$ ($k_p$ is peak_wavenumber). Pass spectrum, a function $\kappa \mapsto E_\varphi(\kappa)$ giving a target radial scalar-variance spectrum, to seed that shape instead: each mode is scaled by $\sqrt{E_\varphi(\kappa)}/\kappa$ (the same construction the velocity uses), so the shell-summed spectrum is $\propto E_\varphi(\kappa)$ and the amplitude is fixed by the variance rescaling — e.g. an Obukhov–Corrsin form from Phenomenology.

domain is the FixedDomain the field is generated on; rng is the random stream (defaults to Random.default_rng()).
