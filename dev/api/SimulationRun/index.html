SimulationRun

GBGIsotropicTurbulence.SimulationRun — Module
SimulationRun

The run layer:

  • Simulation — the assembled state of a case.
  • advance!, run! — advance one iteration; observe and advance until the callback stops the run (the callback is the observation — the thing that reads the run each iteration — and its return decides continuation).
  • StationarityCriterion, warmup! — the packaged spin-up-to-stationarity observation, and its one-line sugar.
  • current_time, current_step — the elapsed time and step count.
  • flow_parameters — the run's measured flow state as a Phenomenology FlowParameters.

A Simulation is a container, not a reading surface: read the state through sim.state and the deposited observables through sim.cache, with the observables and cache accessors that own them.

source

The simulation

The assembled, ready-to-run case — the front-door Simulation(; grid_points_per_axis, viscosity, …) and the domain-taking Simulation(domain; …) constructors. Read its measured state by applying the Observables to sim.state — for example kinetic_energy(sim.state.velocity_spectral) in a run! callback.

GBGIsotropicTurbulence.SimulationRun.Simulation — Type
Simulation(; grid_points_per_axis, k_max_η = 2, kinetic_energy = 1.5,
             side_length = 2π, element_type = Float64, array_type = Array,
             dealiasing = TwoThirds(), kwargs...)
Simulation(domain; k_max_η = 2, kinetic_energy = 1.5, kwargs...)

A ready-to-run case — the FixedDomain, the IntegratorBuffers, the ResolvedGenerator (the equations of motion, carrying the FlowConditions and the assembly scratch), the chosen integrator, the ResolvedFields state (the velocity $\hat{\boldsymbol{u}}$ and passive scalar $\hat\varphi$ in spectral representation), the ObservablesCache observation cache, any Tracers, and a clock. The first form is the front door: from grid_points_per_axis and side_length it builds every piece with sensible defaults, seeds a divergence-free velocity (and, with scalar = true, a mean-zero scalar $\varphi$), and returns a Simulation at $t = 0$ ("front door" names exactly this convenience form throughout — the constructor that builds every component for you); the second takes a FixedDomain you built yourself. Advance it with advance! / run! / warmup!; read its measured state by applying the observables to its state fields (e.g. kinetic_energy(sim.state.velocity_spectral)) or through the cache's deposited observables (velocity_physical(sim.cache), vorticity_physical(sim.cache)), summarize it with flow_parameters, and track its progress with current_time / current_step.

Setting the Reynolds number

By default the run is forced and stationary — a BandRescaling holds the total (whole-field) energy at kinetic_energy (i.e. over = :total ) — and the viscosity is chosen from the grid rather than supplied:

The default holds ``k`` fixed, so ``k`` is not a measurable of the default run

BandRescaling is a deterministic clamp: it rescales the band every step to hold the target, which pins $u'$ (hence the scale of $\mathrm{Re}_\lambda$) and suppresses the physical fluctuation of the quantity it holds. For fluctuation statistics of the held quantity, force with fixed injection (ConstantPower) instead and let $k$ find its own level.

  • Grid mode (no viscosity): the constructor picks the highest Reynolds number consistent with the chosen resolution criterion k_max_η. It reads the dissipation the box sustains from the box-normalized dissipation law Li2008 (in Phenomenology.Scalings), $\varepsilon = (k/G)^{3/2}/L$ with kinetic_energy the kinetic energy $k$, side_length the side $L$, and $G$ a dimensionless constant calibrated on box-confined DNS ($\approx 0.9$; Li et al. 2008), then sets $\nu$ so that $\kappa_{\max}\eta$ equals k_max_η — the resolution criterion, with $\kappa_{\max}$ the max_wavenumber (the dealiasing cutoff, not the grid Nyquist) and $\eta$ the Kolmogorov (dissipation) microscale. Since $\kappa_{\max}\eta = f\pi \eta/\Delta x$ — $\Delta x = L/N$ the grid spacing — with $f$ the retained-Nyquist fraction, k_max_η = 2 gives $\Delta x \approx \eta$ for the default $2/3$ rule ($f = 2/3$); a wider-band strategy (larger $f$) resolves a finer dissipation scale $\eta$ on the same grid at the same k_max_η — which credits the whole retained band as clean signal, exact for TwoThirds and PhaseShift, approximate for HouLi, whose top of band is damped rather than exactly dealiased. The kinetic_energy and side_length fix the units; the grid and k_max_η fix $\mathrm{Re}_\lambda \sim N^{2/3}$. The chosen $\nu$, $\varepsilon$, and $\mathrm{Re}_\lambda$ are logged.
  • Explicit mode: pass viscosity and it is used directly (k_max_η is ignored) — for a decaying run (velocity_forcing = NoForcing()) or manual control. Grid mode is calibrated on a stationary forced balance (Li2008's $G$ is fitted to forced-isotropic DNS), so a decaying run should set $\nu$ explicitly: the resolution it buys is only meaningful while the box sustains the energy the law assumes.

Arguments

All keyword except domain (below). The ones marked (front door only) configure the FixedDomain and are consumed by the first form; the rest are forwarded to the Simulation(domain; …) form.

  • grid_points_per_axis — the number of grid points $N$ along each side (front door only); required.
  • domain — a pre-built FixedDomain. This one is positional, not a keyword: it is the argument of the second form, Simulation(domain; …) (the front door builds one for you from grid_points_per_axis, side_length, dealiasing, element_type, array_type).
  • k_max_η = 2 — the resolution criterion $\kappa_{\max}\eta$ used to set $\nu$ in grid mode (the keyword spells $\kappa_{\max}$ in ASCII); $\ge 1.5$ is well-resolved, higher trades Reynolds number for margin.
  • viscosity — the kinematic viscosity $\nu$ (sets $\mathrm{Re} = 1/\nu$); omit for grid mode.
  • kinetic_energy = 1.5 — the initial, and when forced the held, kinetic energy $k$; 1.5 gives an r.m.s. velocity $u' = \sqrt{2k/3} = 1$.
  • side_length = 2π — the box side $L$ (front door only).
  • element_type = Float64, array_type = Array — the real element type and storage backend (front door only).
  • dealiasing = TwoThirds() — the DealiasingStrategy ($2/3$ sharp, HouLi smooth, or PhaseShift); it sets $\kappa_{\max}$ and hence the CFL step (front door only).
  • schmidt = 1.0 — the Schmidt number $\mathrm{Sc}$ (scalar diffusivity $\varkappa = \nu/\mathrm{Sc}$).
  • velocity_forcing , scalar_forcing — an AbstractForcing (or a DeferredForcing from an operator-free constructor); velocity_forcing defaults to a BandRescaling holding the total (whole-field) energy at kinetic_energy (over = :total), scalar_forcing to NoForcing(). The velocity and scalar are forced independently.
  • scalar = false, scalar_variance = 1.0 — whether to evolve a passive scalar (a mean-zero $\varphi$), and its initial variance.
  • peak_wavenumber = 2.0 — the large-scale envelope wavenumber $\kappa_p$ of the initial condition, for the velocity and the scalar alike (each shell-summed spectrum peaks at $\kappa_p/\sqrt{2}$); it also sets the integral scale initial_spectrum is evaluated at.
  • initial_spectrum = nothing — a Phenomenology EnergySpectrum (e.g. VonKarman1948()) to draw the initial velocity from, in place of the default large-scale Gaussian; its shape is evaluated at the run's state (its integral scale set to 1/peak_wavenumber (which is the Gaussian envelope's characteristic wavenumber $\kappa_p$, not the shell-spectrum peak — that sits at $\kappa_p/\sqrt{2}$; see random_solenoidal_velocity_spectral!)) and normalized to kinetic_energy.
  • integrator = IFLowStorageRK3(), cfl = recommended_cfl(integrator, domain) — the AbstractIntegrator scheme and its advective-CFL ceiling (adapts to dealiasing).
  • number_of_particles = 0, tracer_scheme = CatmullRom — the number of Lagrangian Tracers and their interpolation scheme, forwarded to the Tracers constructor.
  • particle_integrator = EndpointHeun() — the trajectory time-integration scheme (AbstractParticleIntegrator); its registers are allocated for you.
  • rng — the random stream for the initial condition and the tracer seeding (defaults to Random.default_rng()).

Examples

# Grid mode — a 128³ forced-stationary run, ν set from the resolution criterion:
sim = Simulation(grid_points_per_axis = 128)

# Explicit mode — set ν directly, carry a passive scalar, force at constant power:
sim = Simulation(grid_points_per_axis = 128, viscosity = 5e-3;
                 scalar = true, velocity_forcing = ConstantPower(target = 0.1))

# Domain-first — build the frame yourself, then hand it to the second form:
domain = FixedDomain(grid_points_per_axis = 128, side_length = 2π, dealiasing = HouLi(),
                     element_type = Float64, array_type = Array)
sim = Simulation(domain; viscosity = 5e-3)

Fields

  • domain, buffers, generator, integrator — the FixedDomain, IntegratorBuffers, the ResolvedGenerator (whose conditions field is the run's FlowConditions), and the chosen scheme.
  • state — the ResolvedFields (the evolving û, φ̂).
  • cache — the ObservablesCache: the observables the iteration deposits at its end.
  • tracers, particle_integrator, particle_buffers — the Tracers being advected along with the fields, the trajectory scheme advancing them, and that scheme's registers; all nothing when the run carries no tracers.
  • cfl, clock — the advective-CFL coefficient, and the time/step counter.

Advancing the run

Advance one iteration, or observe-and-advance until the callback stops the run; the packaged stationarity observation and its sugar spin a fresh run up to measurement readiness.

GBGIsotropicTurbulence.SimulationRun.advance! — Function
advance!(sim; dt = nothing)

Advance sim by one timestep in place and return it. With dt = nothing the step size is the advective-CFL value for the current velocity; pass dt to force a fixed step. Advects the tracers, if any, by Heun-in-time on the start- and end-of-step velocities, and updates the clock.

GBGIsotropicTurbulence.SimulationRun.run! — Function
run!(callback, sim)
run!(sim) do sim … end

Observe and advance sim until the observation stops it, and return it. After every iteration — and once at the seeded initial state, before any advance — the callback observes the run as callback(sim): it reads the state and the cached observables, records what it wants, and returns true to continue or false to stop (any other return throws an ArgumentError — the decision may not be left implicit). Only then does the next iteration run: the timestep from the cached maximum speed, the step, the tracer push, and the closing deposits. The schedule never varies with how the run is driven, so the closing deposit's maximum-speed reduction and its host readback happen every iteration even under a fixed dt that never reads them. A run of $n$ iterations therefore observes $n + 1$ instants — the first before any step, the last after the final one, with statistics recorded before the stop.

Stopping is the observation's decision on observables, never a run option: a budget is a callback that accumulates what it budgets. A span of simulation time compares current_time against a target; a step budget compares current_step; an eddy-turnover budget accumulates $\Delta t \varepsilon/k$ from the observables it computes; spin-up to stationarity is the packaged StationarityCriterion. Whatever the callback needs beyond the cached observables it computes itself, at its own cadence, with the exported reductions and recoveries.

Examples

run!(sim) do s
    current_time(s) < 5.0                        # a span of simulation time
end

history = Float64[]                              # record k every iteration; stop at 200 steps
run!(sim) do s
    push!(history, kinetic_energy(s.state.velocity_spectral))
    current_step(s) < 200
end

run!(StationarityCriterion(), sim)               # spin up to statistical stationarity

GBGIsotropicTurbulence.SimulationRun.StationarityCriterion — Type
StationarityCriterion(; gate_scalar = true, gate_skewness = true, min_turnovers = 5,
                        window_turnovers = 4, tol = 0.05, skew_floor = 0.1,
                        max_turnovers = 60)

The packaged spin-up observation for run!: a callback that watches the run settle into statistical stationarity and stops it there — run!(StationarityCriterion(), sim) is the detecting spin-up, and warmup! is its one-line sugar. Use it before measurement on any freshly seeded run; write your own callback instead when the transient length is known (a fixed budget is a three-line callback — see run!).

At each iteration it measures the dissipation $\varepsilon$ — the small scales settle last, so a flat $\varepsilon$ is the strict indicator, where a constant-energy forcing clamps $k$ flat and a fixed-injection forcing makes it ring, which is why $k$ is kept out of the gate — and the kinetic energy $k$, which normalizes the eddy-turnover clock $\Delta t \varepsilon/k$ it accumulates, and tests flatness over a trailing window; it stops the run when every gate holds, or gives up with a warning at max_turnovers.

Arguments

All keyword:

  • gate_scalar — when the run's scalar is forced, also require the scalar variance $\langle\varphi^2\rangle$ to be flat (the scalar settles after the velocity; an unforced scalar has no stationary state and is never gated).
  • gate_skewness — also require the velocity-derivative skewness to have plateaued and reached $\lvert S\rvert \ge \texttt{skew\_floor}$ — the decisive "real turbulence yet" signal: a random-phase field starts at $S \approx 0$ and only a developed cascade reaches $S \approx -0.5$. The transform-heavy skewness is sampled at the storage cadence, not every observation.
  • min_turnovers, window_turnovers, tol — do not test before min_turnovers eddy-turnover times (past the start-up overshoot); flatness is a two-half-window mean comparison over the trailing window_turnovers, relative drift below tol.
  • skew_floor — the minimum $\lvert S\rvert$ for a plateau to count as developed turbulence.
  • max_turnovers — the give-up cap: reaching it stops the run with a warning rather than spinning forever.

The criterion carries its own observation state (the sampled signals and the turnover clock), so build a fresh one per run.

Fields

The plain constructor StationarityCriterion(monitor, max_turnovers, gate_scalar, elapsed_turn, last_time, started) is internal. Note the keyword arguments above do not map one-to-one onto these fields: gate_skewness, min_turnovers, window_turnovers, tol and skew_floor are all stored inside monitor, which holds the sampled series together with the thresholds that judge them.

  • monitor — the sampled signals ($\varepsilon$, $k$, the scalar variance, the skewness) and the gate settings and tolerances that test them.
  • max_turnovers — the give-up cap.
  • gate_scalar — the requested scalar gate (applied only when the run's scalar is forced).
  • elapsed_turn, last_time, started — the turnover clock's state.

GBGIsotropicTurbulence.SimulationRun.warmup! — Function
warmup!(sim; kwargs...)

Sugar, and nothing more: warmup!(sim; kwargs...) is exactly

run!(StationarityCriterion(; kwargs...), sim)

— it spins sim up to a statistically stationary state before measurement and returns it, by running the observation-first loop with the packaged stationarity observation. Every keyword is passed through to StationarityCriterion untouched; its docstring is the home for what is detected (the flat dissipation, the scalar-variance and derivative-skewness gates, the give-up cap) and for every option. For a fixed spin-up budget, write the three-line budget callback instead (see run!).

Examples

warmup!(sim)                          # detect stationarity (ε- and skewness-plateau gates)
warmup!(sim; gate_skewness = false)   # relax the skewness gate (a shorter, looser spin-up)

Flow parameters

Bridge the run's measured state to a Phenomenology FlowParameters, so any reference law can be evaluated at the run's measured state.

GBGIsotropicTurbulence.SimulationRun.flow_parameters — Function
flow_parameters(sim)

The measured flow state of sim as a FlowParameters — the bridge that lets any Phenomenology reference law be evaluated at the run's measured state. The viscosity $\nu$ and the Schmidt number are read from the generator's conditions; the dissipation $\varepsilon$, the r.m.s. velocity $u' = \sqrt{2k/3}$ (from the kinetic energy $k$), the longitudinal integral scale $L_{11}$, and — when the run carries a scalar — the scalar dissipation $\varepsilon_\varphi$ are measured from the current state (the scalar dissipation is left NaN only for a scalar-free run, where the scalar reference laws do not apply).
